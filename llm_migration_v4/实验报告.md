# llm_migration_v4 实验报告：v3 协议放大到 7B 规模

把 v3 的协议（配对种子输入 embedding 扰动采样 + 逐 prompt 指纹 + PCA/逐层 ALS，DP 关闭）**原封不动**放大到 7B 级，用本地模型库 `/data/luo_lixuan/llms` 重跑，回答两个 v3（0.5B）没能回答的问题：

1. 主协议在 7B 上对**真实谱系**（官方 SFT、独立衍生、同底座剪枝变体、跨家族 7B/8B）的判别力如何？
2. **序列级蒸馏**（异规模、同词表）在 hidden 几何里留下的指纹能不能被认出？（v1 蒸馏实验判负，v3 协议下未重验。）

主指标与 v3 一致：DiffIP 逐层 ALS 平均 L2 距离，similarity = exp(−Σd/L)，不用 margin 作判定。所有数字来自本目录脚本与 `scores/*.json`，可复现。

## 1. 为什么放大到 7B

- v3 在 0.5B（victim Qwen2.5-0.5B）上做出 0.52 margin / 32/32 全可分，但 victim 只有 0.5B，负例面板弱（SmolLM2-135M 等更小模型），"难负例"维度缺失。
- v2 的 ROC 标定发现**距离绝对尺度家族依赖**、跨家族全局阈值不可迁移——需要 7B 级、同底座真实衍生 + 跨家族 7B 负例来检验协议是否真正可迁移。
- 本地库中 Llama-2-7b 是唯一拥有"官方 SFT + 独立衍生 + 3 个同底座剪枝变体 + 跨家族 7B/8B"完整谱系面板的家族，故主线选它。
- 蒸馏线选 Llama-3.2：1B 学生 / 3B 教师**同家族、同词表**，蒸馏信号纯净，且 1B 学生 CPU 当天可训完。

## 2. 实验设计

### 2.1 主线（victim = Llama-2-7b-hf，32 层 / D=4096）

| derivative_cn | Chinese-llama-2-7b | 独立真实衍生（第二个正例，v3 没有的维度） |

### 2.2 蒸馏线（victim = Llama-3.2-1B，16 层 / D=2048）

| 角色 | 模型 | 说明 |
|---|---|---|
| victim | Llama-3.2-1B | 基座（base 权重） |
| student_distill | 1B 学生 | 在 Llama-3.2-3B 教师回答上序列级 CE 蒸馏 |
| student_control | 1B 学生 | 同指令/同预算，训练文本换成 Alpaca 原始回答。**关键对照**：区分"学过教师"vs"只是被训练过" |
| neg_llama3_2_3b | Llama-3.2-3B（28 层 / D=3072） | 同家族更大（教师本身） |
| neg_sheared_1_3b | Sheared-LLaMA-1.3B（24 层 / D=2048） | 不同血统、相近规模 |
| neg_qwen2_5_7b | Qwen2.5-7B | 跨家族跨规模（npz 复用主线采集，协议一致） |
| neg_llama2_7b | Llama-2-7b-hf（32 层 / D=4096） | 跨家族跨维度（4096 vs 2048，检验独立 PCA 路径；npz 复用主线 victim 采集） |

蒸馏设置：
- 教师数据：沿用 v1 的 Alpaca 切分（1600 train / 120 heldout），Llama-3.2-3B **base 模型**贪心重新生成回答（max_new_tokens=64，BS=32）。本地 3B 是 base 权重（chat 模板会复述+乱码），故教师生成与双学生训练一律用 **v1 纯 Alpaca 完成格式** `### Instruction:\n{ins}\n\n### Response:\n`，不用 chat 模板——与 v1 协议对齐。
- 学生：Llama-3.2-1B base，3 epoch × 200 step（BS=8，lr=1e-4，答案段计损）。distill 在 3B 教师回答上训（final loss 0.288），control 在 Alpaca 原始回答上训（final loss 0.380）。
- 判定逻辑：若 student_distill 相对 victim 的 similarity 显著高于 student_control，说明指纹来自"教师的 hidden 几何"；若两者接近，则蒸馏信号不可区分（负结论同样有效）。

### 2.3 统一协议（与 v3 逐位一致）

- 输入 embedding 扰动：SCALE=2e-3，配对种子 SEED_SETS=[123, 1123, 2123]，每 set 128 样本（N<128 取前 N），suspect/victim 同 seed 严格配对。
- 32 个 prompt（同 v3 探针集：英 7 / 中 6 / 代码 6 / 数学 6 / 问答 7），逐 prompt 独立指纹、独立打分，不跨 prompt 混合。
- 层：每模型 4 个均匀层（`even_layers`），attention-mask 均值池化。
- 评分：PCA 降 d ∈ {8, 20}（满足 d ≤ 4N−1）→ 逐层 ALS 回退（`diffip.preprocessing.project_sequences` + `diffip.reversion.fit_step_alignment`）→ distance_mean / similarity = exp(−Σd/L)。N ∈ {8, 16, 20, 32, 64, 128}。DP 关闭。
- 采集实现：`output_hidden_states=True` 批量取隐层（无 hook），失败自动降级 batch=1。确定性已冒烟验证（重跑逐位一致）。

读法（诚实结论）：
1. **谱系排序在 7B 上保持**（N=128, d=8）：victim(1.0) ≫ 同底座剪枝(0.53–0.56) > SFT 簇(0.357–0.365) > 独立衍生(0.311) > 跨家族(0.254)。同底座剪枝变体比官方 SFT **更靠近** victim——剪掉 32 层中的 4 层是温和扰动，几何保持度高于 SFT 带来的漂移。这是 v3（负例面板无同底座剪枝）没有暴露的维度。
2. **三种伪装全部隐形**：weight_perm（0.364）/ rep_perm（0.363）/ scale（0.365）与 fine_tune（0.363）在噪声内完全一致。特征空间线性伪装与输入侧置换对 PCA+ALS 指纹不可见，符合设计预期。
3. **prune_dpoff（chat + 剪 4 层，0.357）落在 SFT 簇而非剪枝簇（0.53–0.56）**：指纹跟着"基座 + 是否 SFT"走，剪枝的效应远小于 SFT。base+prune 归 base 簇、chat+prune 归 chat 簇，谱系归属清晰。
4. **跨家族地板稳定**：Qwen2.5-7B 与 Llama-3-8B 均为 0.254（d=8），与 v3 在 0.5B 上的负例地板（0.235–0.240）几乎相同——"无关模型"底线不随规模变化。
5. **绝对值随规模下降**：fine_tune 从 v3 的 0.760（0.5B）降到 0.363（7B），而负例地板不变。N≥64 后各格 std ≤0.013、N=64→128 变化 ≤0.02，收敛行为与 v3 一致。含义：**跨规模不可迁移的是绝对阈值，可迁移的是相对排序**——与 v2 ROC 发现的"尺度家族/规模依赖"一致，实用部署必须家族内+规模内相对标定。
6. **N=20（论文设置）下**：SFT 簇 27–29/32 高于跨家族负例，derivative_cn 仅 20–27/32——独立衍生在小 N 下与负例地板的重叠比官方 SFT 大，检测更依赖大 N。
7. 注意：若"胜负"按**全部**负例（含 3 个同底座剪枝）计，SFT 类 suspect 只有 0–1/32（被难负例压制）——这正是"剪枝副本比 SFT 更像基座"的逐 prompt 体现，两种口径都如实保留。

### 4.3 neg_internlm2_7b 隔离记录

该模型采集出的特征在选层 [21, 31] 全单元格非有限（100,663,296 = 32×3×2×128×4096 个 NaN，含无扰动干净样本）。诊断（`diag_internlm2_nan.log` / `diag_internlm2_attn.log`）：
- 权重全部有限（逐张量校验 0 个非有限）——非 checkpoint 损坏；
- 干净前向：eager（默认实现）下 bf16 从第 2 层、fp32 从第 4 层起全 NaN；
- 第 1 层输出激活幅值已达 ~4800（健康模型为 O(1–10)），前向处于数值不稳定边缘，发散点随 run 漂移；
- SDPA 下单条干净前向有限，但完整采集（32 prompt × 128 样本批量）在第 2 个 prompt 再现非有限，无法稳定产出。

结论：模型 × 环境不兼容（自定义 modeling 代码 + transformers 5.20 CPU），非采集代码或协议问题。按 PLAN 风险表"该模型隔离，其余继续"处理。跨家族面板保留 Qwen2.5-7B + Llama-3-8B（两者数值一致，地板结论不受单模型缺失影响）。若需该模型，建议在 GPU 或 transformers 4.x 环境重试。

## 6. 与 v3（0.5B）对照

N=128、d=8、跨 prompt 均值（v3 数据引自 llm_migration_v3/实验报告.md 第 4 节）：

| 指标 | v3（victim Qwen2.5-0.5B） | v4（victim Llama-2-7b-hf） |
|---|---|---|
| fine_tune（官方 SFT） | 0.760±0.005 | 0.363±0.006 |
| 三种线性伪装 | ≈ fine_tune（0.760/0.760/0.754） | ≈ fine_tune（0.364/0.363/0.365） |
| base + 剪 4 层 | 0.645（4/24 层 = 16.7%） | 0.528–0.559（4/32 层 = 12.5%） |
| 独立衍生 | 无此维度 | 0.311 |
| 跨家族负例地板 | 0.235–0.240（5 个） | 0.254（2 个） |
| fine_tune − 负例 margin | ≈0.52 | ≈0.11 |
| 逐 prompt 胜负（N=20） | 32/32（对全部 5 负例） | 28/32（对 2 个跨家族负例） |
| N≥64 收敛 std | ≤0.005 | ≤0.013 |

读法：
- **保持的**：相对谱系排序、线性伪装隐形、跨家族地板稳定（0.235–0.254）、随 N 的收敛行为。
- **变化的**：绝对 similarity 大幅下降（fine_tune 0.760→0.363），margin 从 0.52 缩到 0.11。7B 上"同家族接近度"的整体数值范围被压缩，而"无关模型"底线不动——**跨规模可迁移的是排序，不是绝对值/阈值**。
- **v3 无法回答、v4 新暴露的**：
  1. 剪枝 vs SFT 的排序**反转**。v3：base+SFT（0.760）> base+prune（0.645）；v4：base+prune（0.53–0.56）> base+SFT（0.363）。两版剪枝比例不同（16.7% vs 12.5%）且模型家族/规模不同，无法完全分离两个因素；但可以确定"剪枝扰动 < SFT 漂移"不是尺度不变的结论。
  2. 序列级蒸馏的几何指纹：v4 判**不可检测**（第 5 节），比 v1 的"认不出教师"更进一步的负结论。

## 7. 局限（诚实记录）

- 全程 CPU、单卡不可用，N=128 是本次预算上限；7B 模型采集 ~30-60min/个，更大 N 或更多 seed set 未跑。
- 每个模型只采一次（无跨 run 方差估计），指纹确定性已冒烟验证但非多机复现。
- DP 关闭（v3 第 6 节已验证 DP-on/off 接近，且 DP-on 需全层数据）。
- 蒸馏学生 1B（7B 学生 CPU 要 1-2 天，未跑）；教师仅 1600 条 Alpaca 指令 ×1 遍贪心。
- 跨维度负例（4096 vs 2048）走各自独立 PCA，分数可比较但 PCA 基不同，解释时需注意。
- Chinese-llama-2-7b 是独立衍生但底座同为 Llama-2-7b，"独立"程度介于正例与同底座剪枝之间，其分数位置需结合谱系解读。

## 8. 小结

**问题 1（主协议在 7B 上对真实谱系的判别力）**：
1. 协议**可迁移到 7B**：相对谱系排序保持（同底座剪枝 0.53–0.56 > SFT 簇 0.357–0.365 > 独立衍生 0.311 > 跨家族 0.254），三种线性伪装（输入置换 / 特征置换 / 各向异性缩放）全部隐形，收敛行为（N≥64 后 std ≤0.013）与 0.5B 一致。
2. **尺度依赖的两个新发现**：(a) 绝对 similarity 随规模压缩（fine_tune 0.76→0.36，margin 0.52→0.11），跨家族地板不动——绝对阈值跨规模不可迁移，只有相对排序可迁移，实用判定必须家族内 + 规模内标定（与 v2 ROC 结论互相印证）；(b) "剪枝 vs SFT"排序相对 v3 反转——7B 上同底座剪枝副本比官方 SFT 更像基座。
3. **难负例是 v4 最大的新维度**：同底座剪枝变体在"高于全部负例"口径下压制所有 SFT 类 suspect（0–1/32）。若鉴定目标是"是否源自基座 X"，剪枝副本应归入同底座一侧——它们与基座的几何距离比 SFT 更近。

**问题 2（蒸馏的 hidden 几何指纹）**：
4. **负结果**：student_distill 与 student_control 在所有 N/d 下差异 ≤0.003（N=128、d=8：0.620±0.003 vs 0.623±0.002），教师本身与无关负例无差别（0.591）。序列级 KD（1600 条指令 × 3 epoch）留下的几何差异淹没在"同基座微调"的共性信号里——**"被蒸馏过"这一属性在 N≤128 预算下不可检测**。

**实用含义**：
5. 本协议适合**家族内 + 规模内**的相对谱系鉴定（SFT/衍生/剪枝/跨家族的排序）；跨家族或跨规模比较必须重新标定。对"同底座"判定，结构变体（剪枝）是强正信号，蒸馏不留下可利用的指纹。
