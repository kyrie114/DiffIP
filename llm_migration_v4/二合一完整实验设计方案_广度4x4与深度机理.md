# 论文实验章节“二合一”终极设计方案（导师 4×4 广度骨架 + 单基座低误报深挖与三大创新机理拆解）

> **核心设计理念（Breadth × Depth 二合一）**：
> 1. **横向广度（100% 保留导师手稿全部要求）**：
>    - **三大核心卖点**：① 性能 $\ge$ SOTA（`REEF`, `HuRef`, `AWM`）；② 计算效率与存储优势显著（`Module B`：**16 KB** 指纹 + 秒级在线对齐）；③ 同基座谱系区分更强（`源 | A | B | C | D` 跨基座矩阵）。
>    - **全矩阵覆盖**：4 个异构/跨代基座（`Llama-2-7b-hf`, `Meta-Llama-3-8B`, `Qwen3-8B-Base`, `mpt-7b`）$\times$ 4 种标准衍生类型（`①剪枝 ±`, `②量化 ±`, `③微调 ±`, `④领域 ±`）+ `Test` 伪装攻击列 + `16 个子图 (Fig. 1)` + `Module C` 消融（PCA 维数 + 层间选择）。
> 2. **纵向深度（融入你的单基座深挖、专打 REEF 软肋与核心创新原理拆解）**：
>    - **单基座深挖（专打 `REEF` 高误报软肋）**：在主基座 `Llama-2-7b-hf` 上，用 **6 个高难异源负例**（含完全同架构同词表但独立预训练的 `llama-7b-hf [Llama-1]` 与 `open_llama_7b`、同维异族 `Baichuan-7B` 与 `mpt-7b`、跨代 `Meta-Llama-3-8B`、跨维 `Qwen2.5-7B`）和 **20 对有序交叉参照标定**（[实验维数层数结果.md](file:///d:/study/Diffip/llm_migration_v4/%E5%AE%9E%E9%AA%8C%E7%BB%B4%E6%95%B0%E5%B1%82%E6%95%B0%E7%BB%93%E6%9E%9C.md)），正面击穿 `REEF` 在无关模型上 CKA 高达 `0.85–0.95` 的假阳性黑洞，展示我们将全部无关负例锁死在 **`0.2525–0.2537`**、全 20 对部署 **AUC `0.9999`** 的统治级优势。
>    - **三大核心创新原理拆解（因果链闭环）**：用**已完成 90% 的实测消融数据**逐一证明本方法三个核心设计为何缺一不可：
>      1. **为什么要做“单点配对微扰”？**（`2×2 点云形态×对齐算子` + `Shuffle 打破配对消融` + `RankGauss 正态化`：证明核心信号来自同一输入微扰方向激发的**局部 Jacobian 配对几何**，而非跨句子宏观语义或静态激活边缘分布）；
>      2. **为什么要做“$\mathrm{GL}(d)$ ALS 逆对齐”？**（`线性/旋转+非恒定 RMSNorm 伪装` + `9 种非线性变换` + `等 RMS 无关激活掺入曲线`：证明一般可逆矩阵求逆对正交/非正交重参数化与特征污染的强韧性）；
>      3. **为什么要做“同 Prompt 相对间隔 $\Delta_p$”？**（揭示 $r=0.956$ 跨模型探针共变性，对比 `同 Prompt 相减` vs `全局绝对阈值 / 跨规模阈值 / 减常数 / 错位 Prompt 相减`，证明唯有 $\Delta_p$ 能将留出集 AUC 从 `0.644–0.702` 提升至 `0.9998–1.000`）。
>    - **严谨的作用域边界**：如实报告 `3B→1B` 序列级黑盒蒸馏阴性对照（AUC `0.493`）与分词切分一致性前提（[优点验证_小模型_20261112.md](file:///d:/study/Diffip/llm_migration_v4/%E4%BC%98%E7%82%B9%E9%AA%8C%E8%AF%81_%E5%B0%8F%E6%A8%A1%E5%9E%8B_20261112.md)），做到滴水不漏。

### 2.3 Section 4.4：核心创新原理拆解 —— 为什么必须做“单点配对微扰 + ALS + $\Delta_p$”？

本节直接回应审稿人对方法创新性的核心拷问，通过 **三组已完成实测的控制变量实验（Tables 4, 5, 6 + Fig. 5(a)-(b)）** 给出因果级证明：

#### （1）拆解一：为什么必须是“单点配对微扰”？（`Table 4` & `Fig. 5(a)`）
我们将“点云生成方式”与“配对关系/对齐算子”做正交拆解（结合 `0.5B 2×2 矩阵`、7B `suite_sota.py mechanism` 以及 `实验 E` 实测数据）：

| 实验变体设置 | 点云输入类型 | 种子配对关系 | 对齐算子 | 7B 微调正例得分 (`fine_tune`) | 无关负例最高分 (`Max Neg`) | 逐 Prompt 胜率 (`/32`) | 抗各向异性缩放 (`scale`) | 核心物理机理结论 |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **① `REEF` (Baseline)** | 200 条异构句子 (`TruthfulQA`) | 句子级对应 | Linear CKA | 高 (`~0.94`) | **极高 (`0.84–0.94`)** | N/A (全局单值) | ❌ 退化 | 跨句子主题语义混杂导致无关模型高假阳性 |
| **② `Perturb + CKA`** | 单 Prompt 微扰云 (`128×D`) | **保持同种子配对** | Linear CKA | 高 | **显著压低** | 高 | ❌ 退化 | **证明“单点微扰”剥离了句间宏观语义**，但 CKA 不抗非均匀通道缩放 |
| **③ `Shuffle` (实验 E)** | 单 Prompt 微扰云 (`128×D`) | **随机打乱配对 (`perm(128)`)** | PCA8 + ALS | **`0.253 ± 0.008`** | `0.254 ± 0.008` | **`5 / 32` (崩塌)** | — | **铁证**：激活点云完全未变，仅打破种子配对即跌回无关地板，证明信号纯粹来自**同方向局部 Jacobian 响应** |
| **④ `RankGauss` (实验 E)** | 单 Prompt 微扰云 (`128×D`) | **保持同种子配对** | 逐维正态化 + ALS | **`0.348 ± 0.008`** | `0.254 ± 0.008` | **`32 / 32` (全胜)** | ✅ 稳健 | **反证**：即使强行抹平各通道边缘分布形状，只要保留配对轨迹，谱系依然 100% 检出 |
| **⑤ `Ours (Full)`** | 单 Prompt 微扰云 (`128×D`) | **保持同种子配对** | **PCA8 + ALS + $\Delta_p$** | **`0.363 ± 0.006`** | **`0.254 ± 0.008`** | **`32 / 32` (全胜)** | **✅ 严格不变 (`0.365`)** | 兼具零宏观语义混杂、局部配对几何锁定与 $\mathrm{GL}(d)$ 仿射不变性 |

#### （2）拆解二：为什么必须用“同 Prompt 相对间隔 $\Delta_p$”？（`Table 5` & `Fig. 5(b)` —— 100% 实测数据）
直接整合 [实验ABC结果.md](file:///d:/study/Diffip/llm_migration_v4/%E5%AE%9E%E9%AA%8CABC%E7%BB%93%E6%9E%9C.md)（实验 B）与 [实验FG结果.md](file:///d:/study/Diffip/llm_migration_v4/%E5%AE%9E%E9%AA%8CFG%E7%BB%93%E6%9E%9C.md)（实验 F）的实测结论：
- **核心发现**：7B 微调正例 `fine_tune` 与无关模型 `Qwen2.5-7B`、`Llama-3-8B` 在 32 条 Prompt 上的原始相似度皮尔逊相关系数高达 **$r = 0.9556$ 与 $r = 0.9560$**（控制 Prompt 字符长度后偏相关仍为 **$0.9556$**！）。这意味着**不同 Prompt 本身的局部流形曲率（“易对齐 Prompt vs 难对齐 Prompt”）主导了绝对分数的基线起伏（0.010 到 0.853）**。
