# 这次实验说明了什么

这次接在 v4 已完成的 7B 评分之后。采集和 ALS 没有重做。问题是那份 similarity 能不能当成一条判定，以及什么操作会把谱系打掉。

细节分别在 `实验ABC结果.md`、`实验DE结果.md`、`实验FG结果.md`。判定代码在 `lineage.py`。

## 绝对分数不能当阈值

even4、N=128、d=8 上，fine_tune 的均值是 0.363，两个跨家族负例都是 0.254。逐条 prompt 的标准差大约是 0.25。fine_tune 和 Qwen2.5-7B、Llama-3-8B 的逐 prompt 均值相关都是 0.956。

所以一条全局阈值对不上。低误报的阈值被负例的高分 prompt 抬到 0.786，SFT 的留出召回只剩约 0.06。部署正类对负例的 AUC 是 0.702。

把 0.5B 上分开微调与负例的阈值 0.499 搬到 7B，只接受 32% 的 SFT，同时误接 23% 的跨家族逐 prompt 分数。绝对阈值不能跨规模拿走。

字数解释不了那个相关，相关只有 0.022。去掉英文、中文、代码、数学、问答这五类的类别均值之后，偏相关仍是 0.949。类别会抬高或压低整组分数。问答类的 fine_tune 均值是 0.077，数学类是 0.533。类内相关仍然很高。共同成分在单条 prompt 上。

## 必须减同一条 prompt

分数改成 `sim(模型) − sim(一个跨家族参照)`。另一个负例留出。seed 0 标定，seed 1 和 seed 2 评估。通过线是强正例和 SFT 的留出召回都至少 0.90，误报至多 0.10。

even4 上两个方向都通过。SFT 留出召回是 0.97 到 1.00。部署 AUC 是 0.9998。独立衍生的留出召回大约是 0.5。它的间隔中位数是 0.019，SFT 是 0.095，低误报阈值是 0.016。稀疏剪枝和官方 SFT 能用这条线。Chinese-llama 不能和它们共用一条高召回阈值。

减错 prompt 时，AUC 掉到 0.644，留出召回掉到约 0.06。只减参照在 32 条 prompt 上的平均数，AUC 是 0.702，和绝对分数一样。mid2 和 N=20 用同一条规则也不通过。

## 中间两层保持排序，不改默认

mid2 是已存储 4 层里的第 1、2 层，不是 v3 的全层中间 2 层。N=128、d=8 的排序仍是结构变体 0.43–0.48，SFT 簇 0.245–0.250，独立衍生 0.236，跨家族 0.170。官方 SFT 对跨家族仍是 32/32。独立衍生从 25/32 变成 27/32。三种线性伪装仍和微调分不开。

SFT 到地板的间隔从 0.109 收到 0.079。默认层留在 even4。蒸馏仍是阴性。mid2 上 distill 0.868，control 0.870。

## 配对在，谱系就在

打乱 fine_tune 的样本配对之后，相似度从 0.363 掉到 0.253，和跨家族地板重合，胜负只剩 5/32。分数用的是同一份噪声下的配对几何。

逐维单调变换藏不住。符号保持平方是最强的一条，0.344，31/32。把每一维换成正态分位数之后仍是 0.348，32/32。

按系数掺入 Llama-3 会把幅度算错。fine_tune 的 RMS 是 1.957，Llama-3 是 0.772，比值 2.54。两朵云的相关是 0.034。系数上的 75% 里，能量仍有约 42% 来自 fine_tune，对 Qwen 是 29/32。全局缩放会被 ALS 吃掉。只把 fine_tune 除以自己的 RMS，和已存分数的最大差是 6.7e-6。

拉齐 RMS 之后，75% 的均值掉到 0.259，进了地板以上 0.020 的带。逐 prompt 对 Qwen 仍是 27/32。均值贴地板，配对比较没有倒。50% 仍是 0.312，29/32。

## 判定入口

`LineagePanel.from_score_dir` 读现有的 `main_*.json`，不重新打分。`decision().passed` 只在 even4、N=128、d=8、两个参照方向都满足上面的留出规则时为真。`derivative_cn` 出现在召回里，不参与通过。`win_counts()` 是 seed 0 上对两个跨家族模型的逐 prompt 胜负，不是通过。

目录名叫 `scores` 还不够。fine_tune 在 N=128、d=8 的均值低于 0.30 会拒绝加载。even4 的这个均值是 0.363，mid2 是 0.249。`scores_mid2` 可以读胜负，但 `passed` 为 false，且没有方向结果。

`python test_lineage.py` 已通过。对抗检查重跑了同一套断言和一份独立探针，没有一条能证明判定违背上述规则。
