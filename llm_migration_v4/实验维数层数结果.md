# 维数、层数与无关模型

规则在 `试验方案_维数层数与无关模型.md`。实验一、实验二已经做完。实验三的三个新无关模型还在采集。

## 实验一：维数留在 8

N=128，已有的均匀 4 层特征，不重跑模型。比较 8、10、15、20、30、40 维。判定沿用实验 D：同一条提示上减去一个无关参照，另一个留出；种子 0 定阈值，种子 1 和 2 检验。通过线是强正例和官方微调簇的留出召回都至少 0.90，误报至多 0.10。

间隔取两个方向里更差的那个：fine_tune 在种子 1 和 2 上的间隔中位数。替换 8 维要间隔至少高 0.02，且标准差不高过 0.01。六个维都通过。间隔从 8 维的 0.092 到 40 维的 0.098，只高 0.006。标准差从 0.080 降到 0.077。不到替换线。默认维数留在 8。

| 维 | 通过 | 间隔 | 标准差 | Qwen 参照的留出召回 | Llama-3 参照的留出召回 |
|---:|---|---:|---:|---|---|
| 8 | 是 | 0.092 | 0.080 | 1.00 / 0.969，误报 0 / 0 | 1.00 / 0.975，误报 0.031 / 0 |
| 10 | 是 | 0.093 | 0.079 | 1.00 / 0.969，误报 0 / 0 | 1.00 / 0.994，误报 0.094 / 0.031 |
| 15 | 是 | 0.095 | 0.078 | 1.00 / 0.975，误报 0 / 0 | 1.00 / 1.00，误报 0.062 / 0.031 |
| 20 | 是 | 0.092 | 0.078 | 1.00 / 0.981，误报 0 / 0 | 1.00 / 1.00，误报 0.094 / 0.062 |
| 30 | 是 | 0.098 | 0.077 | 1.00 / 1.00，误报 0 / 0.031 | 1.00 / 0.994，误报 0.031 / 0 |
| 40 | 是 | 0.098 | 0.077 | 1.00 / 1.00，误报 0 / 0.031 | 1.00 / 1.00，误报 0.031 / 0.031 |

8 维和已存分数的最大绝对差是 2.0e-5。Qwen 方向的阈值是 0.0161，留出微调召回 1.00 和 0.969，和实验 D 对得上。20 维有 8 个格子和已存分数差过 1e-3，最大 4.3e-3，出在 scale、提示 2、种子 2。这是随机 PCA 的格子差，不是 8 维没复现。脚本按预先写的 1e-3 门把原因记成 rescore_mismatch。同一轮的间隔比较同样把默认留在 8，原因是差距不够（gap_not_clear）。后续实验用 8 维。

中文衍生的留出召回仍在 0.47 到 0.56，不参与选维。

## 实验二：层数留在均匀 4 层

小盘重采了全部层：受害模型、官方微调、SparseGPT、Qwen2.5-7B、Llama-3-8B。Qwen 是 28 层，其余是 32 层。均匀 4 层和旧特征逐点一致，最大差是 0。用这四层、8 维重打的分数和实验一的最大差是 4.0e-6。复现门过了。

小盘上的通过线仍是留出召回至少 0.90、误报至多 0.10。强正例只有 SparseGPT。微调簇是 fine_tune，加上从它推导的 rep_perm 和 scale。weight_perm、prune_dpoff、另外两种剪枝不在这张盘上。

| 抽法 | 通过 | 间隔 | 标准差 |
|---|---|---:|---:|
| 均匀 4 层 | 是 | 0.092 | 0.080 |
| 均匀 8 层 | 是 | 0.066 | 0.079 |
| 全部层 | 否 | 0.043 | 0.066 |
| 最后 4 层 | 否 | 0.033 | 0.065 |

均匀 8 层仍通过，但间隔从 0.092 收到 0.066，没有变大。全部层的微调簇留出召回掉到 0.71 和 0.79，一个方向的误报是 0.125。最后 4 层的微调簇召回在 0.66 到 0.78。默认层留在均匀 4 层。Qwen 的全部层是它自己的 28 层，和受害模型配对时受害模型取 even_layers(32, 28)；同为 32 层的模型之间是 32 对 32。

后续实验用 8 维、均匀 4 层。
