# 本地可用模型

2026-11-07 核对。本地库里有 52 个模型目录，权重合计约 761 GB。每个目录都有 `config.json`。权重文件名里的分片序号和 `-of-N` 对得上，没有缺片。

这次只读了配置和权重文件，没有逐个用 transformers 做前向。分片齐全不等于当前离线环境都能跑。

表里的 H 是隐藏维，L 是层数，GB 是权重文件的磁盘大小，不含词表和配置。配置里的 `torch_dtype` 和磁盘上的实际宽度不一定一致，所以不列精度。

v4 从 `llm_migration_v4/common.py` 的 `MAIN` / `DISTILL` 按目录名取模型。`weight_perm`、`prune_dpoff` 打分时从 `Llama-2-7b-chat-hf` 变出来。`rep_perm` 和 `scale` 从 `fine_tune` 特征变出来。这四项没有单独的权重目录。两个学生在 `llm_migration_v4/ckpt/`，不在这 52 个里面。
