# 实验 F / G 结果

这两件按 pstack 里的两条规则来。F 先把前提写下来再检验（attack the premise）：实验 B 的全局阈值和实验 D 对独立衍生都没把「全部同源模型」分成一类。G 在引用「掺 75% 仍有 29/32」之前，先排除这个数测的是别的东西（explain the number）。判定写在脚本开头，跑完没有改。

| 实验 | 结论 |
|---|---|
| F 前提 | 必须减同一条 prompt。减错 prompt，或只减一个常数，留出规则都不通过。SFT 和独立衍生不是同一类 |
| G 掺入比例 | fine_tune 的 RMS 是 Llama-3 的 2.54 倍。按系数掺 75% 时，能量里仍有约 42% 来自 fine_tune。把幅度拉齐之后，75% 的均值掉到地板，但逐 prompt 仍赢 Qwen 27/32 |

## 实验 F

前提：实验 D 能分开，是因为减去了同一条 prompt 上的跨家族参照，剩下的是谱系。若减错 prompt，或只减掉参照在 32 条 prompt 上的平均数，仍然能通过同一条留出规则，这个前提就不成立。

置换用 `Generator(42)`，32 条 prompt 没有一条留在原位。通过线与实验 D 相同。N=128、d=8。下表是 Qwen 当参照、Llama-3 当检验；反方向数字同级。

| 减法 | 留出 SFT 召回 | 留出误报 | 部署 AUC | 独立衍生留出召回 | 是否通过 |
|---|---|---|---|---|---|
| 同一条 prompt | 1.00 / 0.97 | 0.00 / 0.00 | 1.000 | 0.53 / 0.47 | 通过 |
| 错开的 prompt | 0.11 / 0.06 | 0.00 / 0.06 | 0.644 | 0.09 / 0.13 | 不通过 |
| 只减一个常数 | 0.06 / 0.06 | 0.00 / 0.03 | 0.702 | 0.09 / 0.06 | 不通过 |

只减常数时的 AUC 0.702，和实验 B 里绝对分数的部署 AUC 一样。错开 prompt 之后，SFT 相对参照的中位数间隔还在 0.092，但低误报阈值被尾巴抬到 0.665，留出召回掉到一成。起作用的是逐 prompt 对齐，不是整体高一截。

SFT 的对齐间隔中位数是 0.095。独立衍生是 0.019，而低误报阈值是 0.016。衍生刚好贴在两个负例互相之间的缝上，所以召回停在一半。它们不是同一个正类，不该共用一条高召回阈值。

0.956 的相关不是 prompt 字数。字数和 fine_tune 的相关是 0.022，和两个负例都不到 0.03。去掉字数之后，fine_tune 和 Qwen 的偏相关仍是 0.956。共同成分在，但不是长度。这次没有再去猜它是什么。

## 实验 G

先核对原始文件：`scores_break/mix_llama_075.json` 在 seed 0、N=128、d=8 上对 Qwen 是 29/32，96 个分数的均值是 0.304。和汇总一致。

幅度：fine_tune 的 RMS 是 1.957，Llama-3 是 0.772，比值 2.54。隔 64 个元素抽样的相关是 0.034，两朵云几乎不重叠。在不相关的前提下，按系数去掺时，fine_tune 占的能量是：

| 系数里 Llama-3 的比例 | fine_tune 的能量占比 |
|---|---|
| 0.25 | 0.983 |
| 0.50 | 0.865 |
| 0.75 | 0.417 |

所以原来的「掺进四分之三」并不是四分之三的能量，fine_tune 还占四成。全局缩放本身会被 ALS 吃掉：把 fine_tune 除以自己的 RMS 再打分，和已存分数的最大差是 6.7e-6。要改的是两者的相对权重，不是整体乘一个常数。

拉齐 RMS 之后再混，裁判仍是 Qwen：

| 拉齐后 Llama-3 的比例 | similarity | 对 Qwen | 判定 |
|---|---|---|---|
| 0（只做归一） | 0.363±0.006 | 32/32 | 缩放被吃掉 |
| 0.25 | 0.337±0.006 | 32/32 | 分数下降，谱系还在 |
| 0.50 | 0.312±0.008 | 29/32 | 分数下降，谱系还在 |
| 0.75 | 0.259±0.007 | 27/32 | 均值落到地板带（≤0.274），逐 prompt 没有倒 |

0.75 这一档按预先写的规则算「藏住」，因为均值 0.259 进了地板以上 0.020 的带。这条规则是「均值或胜负，满足一条即可」。胜负本身是 27/32，没有掉到 20/32 以下。均值贴地板、逐 prompt 仍多半赢，和实验 F 是同一件事：绝对高度被 prompt 抬走，配对比较还在。拉齐之后，要让均值落到地板，得把能量里的 fine_tune 压到大约一成（0.75 对 0.25 的平方比）。
