# 自定实验 D / E

上一轮按设计书做完 A/B/C。B 的失败是：绝对 similarity 被 prompt 难度带着走，全局阈值没有工作点，但同一条 prompt 上的配对比较仍然 32/32。C 的结果是：逐维单调非线性藏不住谱系。下面两件只针对这两个缺口，规则在跑之前写死。

不改采集、不改 ALS、不覆盖 `scores/` 与 `scores_mid2/`。主配置仍是 N=128、d=8。结构变体是正例。胜负只对跨家族负例。

## 实验 D：逐 prompt 相对分数

问题：把「和同 prompt 的参照模型比」写成一条阈值之后，留出的另一个负例还能不能分开。

分数：`m = sim(模型) − sim(参照)`，同一 prompt、同一 seed。参照只用一个跨家族模型，检验用另一个。两个方向都做：参照 Qwen2.5-7B、检验 Llama-3-8B，以及反过来。不用两个负例的最大值，避免检验负例泄漏进分数。

正类与实验 B 相同：强 = 三个稀疏剪枝，SFT = fine_tune / 三种线性伪装 / prune_dpoff，难 = derivative_cn（单独报，不进部署正类）。

操作点与实验 B 相同：seed 0 标定，seed 1 和 2 评估。`m >= t` 判正。t(FPR=0) = 标定集上检验负例的 m 的最大值；t(FPR=0.05) = 该组的 95% 分位数。通过：留出 seed 上强正例与 SFT 的 TPR 都 ≥ 0.90，且 FPR ≤ 0.10。even4 与 mid2 分开。

描述量（不参与选阈值）：fine_tune 与每个负例的逐 prompt 均值的 Pearson 相关。用来核对「绝对分被 prompt 难度抬走」是不是共有的。

## 实验 E：什么能把谱系打掉

只改 fine_tune 的特征，受害模型仍是 Llama-2-7b。even4。恒等重跑必须在 N=128、d=8 上与已存分数最大绝对差 ≤ 1e-4，否则整组作废。

| 名字 | 变换 |
|---|---|
| ident | 原特征 |
| shuffle | 每个 (prompt, seed, N) 用种子 `1000 + prompt*10 + seed_set` 打乱样本轴，各层用同一置换。只破坏配对，不改数值 |
| mix_llama_025 / 050 / 075 | `(1−α)·fine_tune + α·Llama-3-8B`，α = 0.25、0.50、0.75。两者都是 4096 维，逐元素相加 |
| mix_deriv_050 | `0.5·fine_tune + 0.5·Chinese-llama-2-7b` |
| rankgauss | 在参与评分的 N 个样本上，逐层逐维按次序做成标准正态分位数。并列用稳定排序打破 |

判定（N=128、d=8）：

- shuffle：打掉配对应当成功。成功 = 对两个跨家族负例的胜负 ≤ 20/32，或均值 ≤ 0.274（地板 0.254 + 0.020）。若仍 ≥ 30/32 且均值靠近 0.363，则「分数依赖配对」不成立。
- rankgauss：沿用 C 的带。与 0.363 相差 ≤ 0.018 且胜负 ≥ 30/32 为稳健；均值 ≤ 0.274 或胜负 ≤ 20/32 为攻击成功；介于两者为部分有效。
- mix_llama：胜负只对 Qwen（掺入的是 Llama-3，不能拿它当裁判）。藏住 = 对 Qwen 的胜负 ≤ 20/32，或均值 ≤ 0.274。三条 α 都报，不另选 α。
- mix_deriv：胜负对两个跨家族负例。藏住的标准同上。

N=20 只作辅助。若只有小 N 看起来像攻击成功，先算小样本波动。
