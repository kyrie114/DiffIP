## 0. 一页决策摘要

### 0.1 要不要做

| 问题 | 结论 | 依据（已核实） |
|---|---|---|
| 主协议还值不值得做？ | **值得，但只做家族内+规模内的相对鉴定** | N=128、d=8：结构变体 0.53–0.56 > SFT 簇 0.357–0.365 > derivative_cn 0.311 > 跨家族 0.254；排序保持，绝对阈值随规模压缩（fine_tune：v3 的 0.760 → v4 的 0.363；跨家族地板 0.235–0.240 → 0.254，几乎不动） |

**总判读**：v4 = **一个阳性（7B 谱系排序可迁移）+ 一个有结论的阴性（序列级蒸馏不可检）**。下一轮只回答三个被点名的缺口（RQ1a/b/c），不扩面板、不加 N、不改主指标。

### 0.2 先做什么（只改一类；含时间预算）

| 优先级 | 实验 | 对应 RQ | 动的变量（只这一类） | 不动的 | 新采集？ | 粗预算 |
|---|---|---|---|---|---|---|
| **P0** | 实验 A：mid2 vs even4 消融 | RQ1a | 层子集：已存 4 个均匀层里的中间 2 层 vs 现用 4 层 | 协议、面板、N/d、主指标 | 否（已有 npz） | 评分约十几到三十分钟量级（按已修复 `score.py`；原 even4 主线评分约 15 min） |
| **P1** | 实验 B：家族内 ROC 标定 | RQ1b | **只改判定规则**（如何从已有分数出阈值） | 协议、面板、分数本身 | 否 | 分析脚本，小时级 |

### 0.3 什么叫赢 / 什么叫停

判定一律相对 **跨家族负例**（Qwen2.5-7B、Llama-3-8B）。`sparsegpt` / `wanda` / `gblm` 是同底座结构变体（**正例**），禁止当负例、禁止计入「未赢」分母。

| 实验 | 采纳（接近对应 H1） | 否决 / 止损（接近对应 H0） | 不算赢 |
|---|---|---|---|
| P0 / 实验 A mid2 | 谱系排序与 even4 一致，且 SFT 簇、结构变体对跨家族负例的逐 prompt 胜负不系统性变差 | 排序翻转，或官方 SFT / 独立衍生相对地板明显塌陷 | 绝对 similarity 数值升降本身（已知跨规模会变） |
| P1 / 实验 B ROC | 在家族内、固定规模下，能给出目标 FPR 的操作阈值，且该阈值**不能**直接套到另一规模而不重新标定 | 正负分严重重叠，相对排序也无法落到可用阈值 | 拿未预先登记的 AUC 回头宣称「方法本来就有效」 |
| P2 / 实验 C 非线性伪装 | 伪装后分数仍落在 fine_tune / SFT 簇、对跨家族负例仍可分 → 协议对更强藏匿仍稳健 | 分数掉到跨家族地板附近，谱系被藏住 → 记录攻击成功，进入防御补丁（另立项，本轮不混改协议） | 只重复已看穿的线性置换/缩放 |
| 蒸馏 | — | **原结果保留为阴性**：N=128、d=8 时 distill 0.620 vs control 0.623 | 去掉 control、或把「两学生都高于负例约 0.03」说成蒸馏成功（那是同基座微调共性） |

**两种结果都有效**：实验 C 中，协议仍认出谱系是检测方法的阳性；攻击把分数打到地板是攻击的阳性。禁止只把其中一种写成「实验成功」。

### 0.4 给老师的一句话建议

**先花不到一小时跑完 mid2 重评分，再用已有分数做家族内 ROC；非线性伪装作为下一压力测试。蒸馏线按当前干预结案，不在同一 KD 设定上加 N。**

## 1. 研究问题

本设计回答两个已落地的问题，并派生三个「只改一类变量」的下一轮问题。已落地部分对应 v4 主线（victim = Llama-2-7b-hf）与蒸馏线（victim = Llama-3.2-1B）；下一轮不得回头同时改层选择、样本规模与伪装强度，再声称「因此方法有效」。

**RQ1（谱系判别与迁移）**  
把 v3 协议（配对种子输入 embedding 扰动 + 逐 prompt 指纹 + PCA / 逐层 ALS，DP 关闭）原封不动放大到 7B 后，对真实谱系——官方 SFT、独立衍生、同底座稀疏剪枝变体、跨家族 7B/8B——是否仍有判别力？若有，**什么可以跨规模迁移，什么不可以**？

**RQ2（蒸馏几何指纹）**  
序列级知识蒸馏（异规模、同词表）是否在 hidden 几何里留下可与「仅仅被同预算微调过」相区别的指纹？v1 已判「认不出教师」；本协议在带 control 的设置下重验。

由 RQ1 的尺度依赖结论，下一轮只追三个被点名的缺口（见第 7 节）。伪装不降格为附属压力测试：它仍是 RQ1c，只是执行优先级排在 P2。

- **RQ1a / 实验 A（层消融，待跑）**：当前默认的 4 个均匀层（even4）相对「存储层中的中间 2 层」（mid2）是否改变谱系排序或正–负间隔？
- **RQ1b / 实验 B（标定，待跑）**：既然绝对阈值不可跨规模迁移，家族内 + 规模内的 ROC 标定能否给出可操作的判定点？跨规模迁移命题 T 须写成可证伪形式（见 7.2）。
- **RQ1c / 实验 C（攻击，待跑）**：线性伪装已被看穿（得分 ≡ fine_tune），预注册的非线性攻击族 1–3 能否藏住谱系？

## 2. 假设（可证伪）

每个假设写清：若成立，分数应落在哪一侧；对照什么；用哪套口径判定。主陈述使用协议主配置 **N=128、d=8、跨 32 个 prompt 的均值 similarity**（similarity = exp(−Σd/L)）；辅助查看 N=20（论文设置）与 d=20，但不另立主指标。

### 2.1 对应 RQ1（已用 v4 数据检验）

**H1-排序（相对谱系）**  
- H1₁：同源程度越高，similarity 越高，应出现  
  `victim (≡1) ≫ 同底座结构变体 > 官方 SFT 簇 > 独立衍生 > 跨家族负例`。  
- H1₀：上述角色之间无稳定排序，或跨家族负例插入同源簇内部。

**H1-伪装（线性）**  
- H1₁：三种线性伪装（输入维置换 weight_perm、特征置换 rep_perm、各向异性缩放 scale）对 PCA+ALS 不可见，similarity 应落在 fine_tune 的种子标准差之内，即「伪装 ≡ fine_tune」。  
- H1₀：任一线性伪装相对 fine_tune 出现超出种子波动的下降（向跨家族地板靠近）或上升。

**H1-剪枝簇**  
- H1₁：在 chat 上做整层删除的 prune_dpoff，指纹应跟随「基座 + 是否 SFT」，即落入 SFT 簇，而不是落入 base 上的稀疏权重剪枝簇。  
- H1₀：prune_dpoff 与 sparsegpt/wanda/gblm 同一簇。

**H1-迁移**  
- H1₁：跨规模可迁移的是相对排序与跨家族地板量级；不可迁移的是绝对 similarity / 单一全局阈值（官方 SFT 的绝对值随规模明显下降，而负例地板大致不动）。  
- H1₀：存在一个不依赖家族与规模的绝对阈值，能同时分开 0.5B 与 7B 上的正例与跨家族负例。

### 2.2 对应 RQ2（已用 v4 数据检验；阴性必须保留）

**H2-蒸馏**  
- H2₁：若学生学到教师的 hidden 几何，则 student_distill 相对 victim 的 similarity **显著高于** 同指令、同预算、只把训练文本换成 Alpaca 原始回答的 student_control。  
- H2₀：两者之差落在种子标准差之内，或方向不稳定（distill 不高于 control）。

判定时必须保留 control：没有 control，任何「学生高于跨血统负例」都可能只是「同一 1B 基座被微调过」的共性，不能记作蒸馏贡献。

### 2.3 下一轮（尚无数字，不预设数值）

下一轮假设的完整判定表、唯一改动与失败后怎么办写在第 7 节实验 A/B/C。此处只立方向，避免与已完成假设抢篇幅。

**H3-mid2（实验 A / RQ1a，待跑）**  
- H3₁：若谱系信号主要集中在网络中段，则用 mid2 重评分后，SFT 簇与跨家族负例的间隔不小于 even4，且 H1-排序不翻转。  
- H3₀：排序翻转（例如独立衍生落入地板，或结构变体不再高于 SFT），或间隔明显收窄到无法按第 5 节规则逐 prompt 取胜。  
- mid2 与 v3「全层中的中间 2 层」不是同一组层（v4 的 npz 只存了 4 个均匀层），只能作近似对齐，不得把差异解释成「复制了 v3 默认层」。

**H4-家族内 ROC（实验 B / RQ1b，待跑）**  
- H4₁：在 Llama-2-7B 家族内、以跨家族 7B/8B 为负例做 ROC，可以选到可用工作点（高真正例率、低假正例率），但该工作点的绝对阈值不能原样搬到另一家族或另一规模。  
- H4₀：即使在家族内，正例（含独立衍生）与跨家族负例的逐 prompt 分数严重重叠，不存在稳定工作点。  
- 另立可证伪的跨规模迁移命题 T（见 7.2）：T 成功则须降级「绝对阈值不可迁移」；T 失败则把已有 0.760 vs 0.363 的口头对照升级为一次正式迁移失败。  
- AUC 与工作点数值均为待跑 / 待计算产物，本文不填写。

**H5-非线性伪装（实验 C / RQ1c，待跑）**  
- H5₁：若协议只对线性变换稳健，则非线性伪装应把嫌疑模型的 similarity 从 fine_tune 簇推向更低（接近独立衍生乃至跨家族地板），从而「藏住谱系」。  
- H5₀：非线性伪装仍落在 fine_tune 噪声内（≡ fine_tune），则协议对这类攻击同样稳健，需要再升级攻击或承认当前攻击预算不足。  
- **两种结果都有效**：H5₀ 方向（协议仍稳健）是检测方法的阳性；H5₁ 方向（打到地板）是攻击的阳性。禁止只把其中一种写成「实验成功」。在得出 H5 之前不得改评分协议（N、d、层、扰动种子须锁定）。

## 3. 协议锁定（先固定，再动变量）

下一轮任何对比实验，下列条款视为已冻结。一次实验只允许改写括号中标注的「本轮可动项」之一类。

### 3.1 采集与扰动

- 输入 embedding 扰动：`SCALE = 2e-3`。  
- 配对种子：`SEED_SETS = [123, 1123, 2123]`；每 set 最多 128 个样本（N < 128 时取前 N）；suspect 与 victim **同 seed 严格配对**。  
- 探针：32 个 prompt，与 v3 相同（英 7 / 中 6 / 代码 6 / 数学 6 / 问答 7）。  
- **逐 prompt 独立指纹、独立打分，禁止跨 prompt 混合特征或混合分数后再回溯「某个 prompt 赢了」。**  
- 层：默认每个模型 4 个均匀层（`even_layers`），attention-mask 均值池化。本轮可动项仅见 RQ1a：`V4_LAYER_SUBSET=mid2`，取已存储 4 层中的第 1、2 个（中间两个），**不重新采集**。  
- 采集：`output_hidden_states=True` 批量取隐层；失败自动降级 `batch=1`。确定性已冒烟（重跑逐位一致），本设计不把它当成多机复现方差。

### 3.2 评分

- PCA 降到 d ∈ {8, 20}，并满足 `d ≤ 4N − 1`。  
- 逐层 ALS 回退：`diffip.preprocessing.project_sequences` + `diffip.reversion.fit_step_alignment`。  
- 报告格子：`distance_mean` 与 `similarity = exp(−Σd / L)`。主指标是 distance；对外叙述沿用报告的 similarity，以便与 v3/v4 表格对照。  
- 样本量网格：N ∈ {8, 16, 20, 32, 64, 128}。主结论看 N=128；与论文设置对照时看 N=20。  
- DP 关闭（v3 已验证 DP-on/off 接近，且 DP-on 需要全层数据；v4 未存全层）。  
- 不把 margin 当作判定阈值；margin 只用于描述正–负间隔。

### 3.3 一次只改一类

| 实验 | 冻结 | 唯一可动类 |
|---|---|---|
| 已完成 v4 主线 / 蒸馏线 | 协议全文 | 无（基线） |
| 实验 A：mid2 vs even4 | 模型、N、d、种子、prompt、伪装 | 仅层子集 |
| 实验 B：家族内 ROC | 已有 even4（及随后 mid2）分数 | 仅决策规则 / 标定方式 |
| 实验 C：非线性伪装 | 评分协议与 victim | 仅伪装/攻击生成方式 |

禁止：同时改层、N、伪装，却把分数变化归因于「方法有效」。

## 4. 角色面板

口径先于表格：**sparsegpt / wanda / gblm 与 victim 同底座，是谱系正例（同底座结构变体），不是负例。** 代码键名仍带 `neg_` 前缀，仅为兼容已有 npz/json，显示名与胜负统计必须按正例处理。胜负只对**跨家族负例**计算。蒸馏线必须保留 student_control，否则蒸馏结论无效。

### 4.1 主线（victim = Llama-2-7b-hf，32 层 / D=4096）

| 角色类型 | 键名 / 模型 | 说明 |
|---|---|---|
| Victim（参照） | Llama-2-7b-hf | 基座；自身 similarity = 1、distance = 0 |
| 正例：官方 SFT | fine_tune = Llama-2-7b-chat-hf | 官方 chat SFT |
| 正例：独立衍生 | derivative_cn = Chinese-llama-2-7b | 真实独立衍生；「独立」程度介于 SFT 与结构变体之间 |
| 正例：线性伪装 | weight_perm / rep_perm / scale | 均从 fine_tune 派生（维置换或特征缩放）；检验伪装是否藏住谱系 |
| 正例：结构化层剪枝 | prune_dpoff | chat 上删除第 5/9/14/18 层，DP 关闭 |
| 正例：同底座结构变体 | sparsegpt / wanda / gblm | 同底座、非结构化稀疏权重剪枝，层数不变；预期高分 |
| 负例：跨家族 | Qwen2.5-7B（28 层 / D=3584） | 跨家族、跨维度 |
| 负例：跨家族 | Meta-Llama-3-8B | 跨家族 8B |
| 已隔离，不计入面板 | internlm2-7b | 本环境（transformers 5.20 CPU + 自定义 modeling）激活非有限；按风险表隔离。跨家族地板由上述两枚负例支撑 |

难正例：derivative_cn（小 N 下与地板重叠更大）；prune_dpoff（剪法与结构变体不同，用于防止把「剪枝」当成单一处理）。

### 4.2 蒸馏线（victim = Llama-3.2-1B，16 层 / D=2048）

| 角色类型 | 键名 / 模型 | 说明 |
|---|---|---|
| Victim | Llama-3.2-1B | base 权重 |
| 处理臂 | student_distill | 在 Llama-3.2-3B 教师回答上序列级 CE 蒸馏 |
| **对照臂（必须保留）** | student_control | 同指令、同预算，训练文本为 Alpaca 原始回答 |
| 参照：教师 | Llama-3.2-3B | 同家族更大模型；检验「教师印记」 |
| 负例：近规模异血统 | Sheared-LLaMA-1.3B | 不同血统、相近规模 |
| 负例：跨家族 | Qwen2.5-7B | npz 复用主线采集 |
| 负例：跨家族跨维度 | Llama-2-7b-hf | 4096 vs 2048，独立 PCA 路径；npz 复用主线 victim |

蒸馏训练冻结条款（已执行，下一轮若重训须逐项复述）：教师数据沿用 v1 的 Alpaca 切分（1600 train / 120 heldout）；Llama-3.2-3B **base** 贪心生成（max_new_tokens=64）；格式为纯 Alpaca `### Instruction / ### Response`，不用 chat 模板（本地 3B 为 base 权重）。学生：1B base，3 epoch × 200 step，BS=8，lr=1e-4，答案段计损。已记录 final loss：distill 0.288，control 0.380。

### 4.3 为什么这样分角色

- 把结构变体当负例，会把「正例 A 比正例 B 更像基座」误读成方法失败（旧口径下 SFT 类对「含结构变体的负例集」只有 0–1/32）。该口径已弃用。  
- 跨家族只保留两枚数值稳定的负例：地板结论不依赖被隔离的 internlm2-7b。  
- 蒸馏对照的存在，是 RQ2 能给出「干净阴性」而不是「学生看起来还行」的前提。

## 5. 指标与判定规则

### 5.1 主指标（已定死）

1. **distance_mean**：逐层 ALS 对齐后的平均 L2。  
2. **similarity = exp(−Σd / L)**：与 v3/v4 表格同一变换，便于对照。  
3. 格子中的 ±：similarity 对 3 个 seed set 的标准差；distance 报 3 个 seed set 的均值。  
4. **逐 prompt 胜负**（seed set 0）：某一正例在该 prompt 上的 similarity **高于全部跨家族负例在该 prompt 上的最大值**，计 1 胜。主线负例集 = {Qwen2.5-7B, Llama-3-8B}。报告「x/32」。

主线胜负 **不得** 把 sparsegpt/wanda/gblm 计入负例。蒸馏线胜负按报告原口径：高于全部 4 个蒸馏线负例的 prompt 数；但 **蒸馏是否可检测的判定不看这张胜负表**，只看 distill − control 的差值（见 5.2）。

### 5.2 判定规则

| 主张 | 通过 | 不通过 |
|---|---|---|
| 谱系可分（RQ1） | N=128、d=8 上 H1-排序成立，且官方 SFT / 伪装 / prune_dpoff / 结构变体对跨家族负例的逐 prompt 胜率显著高于随机；独立衍生允许略低，但均值仍应高于地板 | 跨家族插入 SFT 簇或结构变体簇；或 N=128 上多数正例胜负接近 16/32 |
| 线性伪装被看穿 | 三种伪装与 fine_tune 的差落入 seed std | 任一伪装明显偏离 fine_tune 簇 |
| 排序可迁移、阈值不可迁移 | 7B 排序与 0.5B 同型；SFT 绝对值明显下降而跨家族地板量级接近 | 存在共用绝对阈值，或 7B 排序相对 v3 全面打乱（需同时排除剪法混杂，见局限） |
| 蒸馏可检测（RQ2） | 所有主配置下 distill 显著高于 control（超出 seed std，且方向稳定） | 差值 ≤ 种子波动，或 distill 不高于 control → **记阴性，保留数字，不视为实验失败** |

### 5.3 明确不做的事

- 不用未计算的 AUC/EER 替换第 5.1 节主指标。家族内 ROC 是下一轮的**标定实验**，其 AUC 产出后也只作为工作点选择的辅助量。  
- 不用「fine_tune − 负例」的单一 margin 当跨规模阈值。  
- 不把 v3 的 0.52 margin、32/32 全胜直接写成 7B 的成功标准；7B 上间隔会压缩。

### 7.2 实验 B（P1）：家族内 ROC 标定

**RQ-B / RQ1b**：用已有（及实验 A 产出的）distance / similarity，在**同一家族、同一规模**内做相对标定，能否得到可操作的判定阈值；跨家族或跨规模硬搬该阈值是否失败？

这不是把 AUC 补写成 v4 已有主指标。ROC 只是标定手续；输入仍是 distance / similarity 与逐 prompt 分数。

**H-B1（家族内可标定）**  
- H0：在 Llama-2-7B 家族内部，以跨家族样本为负、以同底座正例为正，不存在能同时满足「结构变体与官方 SFT 以高召回被接受」且「跨家族以低误报被拒绝」的操作点。  
- H1：存在至少一条只使用该家族内分数分布定出的阈值（或等价的分位数规则），使预注册的正例组对跨家族负例可分，且该规则在 seed set 之间稳定。  
- 操作点上的通过率 **待计算**，不得事先填写 AUC 或某具体阈值。难正例 derivative_cn（0.311）必须单独报告它落在阈值哪一侧。

**H-B2 / 跨规模迁移命题 T（可证伪写法）**  
- 迁移命题 T：「把 v3 规模（0.5B）上按 fine_tune vs 负例分开的绝对 similarity 阈值，直接用于 v4 的 Llama-2-7B」。  
- 已有对照强烈暗示 T 为假：v3 fine_tune 0.760 vs 地板 0.235–0.240；v4 fine_tune 0.363 vs 地板 0.254。若仍用靠近 0.5B 正例区的绝对阈值，7B 的官方 SFT 会被判成「不够像基座」。  
- 可证伪动作：显式搬一条在 0.5B 协议下分得开的绝对阈值（从 v3 报告的分布导出，不新造分布），在 7B even4 分数上计数误拒 / 误接。不编造 v3 的逐 prompt 分数；若本地没有逐 prompt 文件，均值层面的示意须标明「示意而非正式 ROC」。  
- 若 T 成立（出乎已有叙述）：7B 官方 SFT 与结构变体仍落在该绝对阈值的正侧，且跨家族仍在负侧——则「绝对阈值不可跨规模」需要降级，不能再当总结句。  
- 若 T 失败（与已有叙述一致）：记一次正式的跨规模迁移失败，作为「必须家族内标定」的直接证据，而不是只停留在口头对比 0.760 vs 0.363。

**H-B3（跨家族 / 跨线不可共用一条全局阈值）**  
- 用 Llama-2-7B 上定出的阈值去切蒸馏线（Llama-3.2-1B）的分数，应预期失败：蒸馏线 N=128、d=8 上学生约 0.620–0.623、负例约 0.590–0.591，整条线的绝对尺度与主线 0.25–0.56 不是同一把尺子。  
- 若竟然可共用：证伪「尺度家族依赖」，需重写实用部署建议。  
- 蒸馏线上不得把 0.620 vs 0.623 解释成蒸馏可检。若有人想用 ROC「找出蒸馏阳性」，必须预注册独立标签（distill = 正，control = 负），并且即使算出可分，也要报告效应是否仍 ≤0.003——按锚定，这应失败。

**唯一改动**：只改判定规则的构造方式。不改采集、不改层子集（若要看 mid2，作为实验 A 的附加条件单独列表，不与 even4 混成一张 ROC）。不引入新模型。

|---|---|---|
| 正例-强 | sparsegpt、wanda、gblm | 同底座结构变体，预期最高分 |
| 正例-SFT | fine_tune、weight_perm、rep_perm、scale、prune_dpoff | 线性伪装 ≡ SFT，不单列成负例 |

- 预算：无采集、无训练；写分析脚本与出图，小时级。

### 7.3 实验 C（P2）：非线性更强伪装 / 攻击

**RQ-C / RQ1c**：在线性伪装已被看穿的前提下，对同一套冻结协议施加**非线性**特征或权重侧变换，能否把同源正例的 similarity 压到与跨家族负例不可分，同时不把该变换退化成「换了一个无关模型」？

线性基线（even4、N=128、d=8，不可改写）：weight_perm 0.364、rep_perm 0.363、scale 0.365，均 ≡ fine_tune 0.363。攻击的对照锚是 **fine_tune，不是 victim**。

**H-C1**  
- H0（攻击成功）：至少一类预注册的非线性伪装，其 similarity 相对 fine_tune 产生稳定下降，并落入与跨家族地板（0.254）不可分的区间，从而使该样本对跨家族负例的逐 prompt 胜率系统性下降。  
- H1（协议仍稳健）：预注册的非线性变换仍然 ≡ fine_tune（或仍明显高于地板、保持对跨家族可分），攻击失败、协议稳健。  
- **两种结果都有效**：H1 是检测方法的阳性（更强攻击下仍认出谱系）；H0 是攻击的阳性（协议被打破）。禁止只把其中一种写成「实验成功」。

**H-C2**：若某变换只有在同时改层子集、改 PCA 维数或取消配对种子时才把分数打到地板，则不计入「非线性伪装有效」，而计入协议违规。

**唯一改动**：只改伪装/攻击的函数类。冻结 even4（除非实验 A 已表明必须并列 mid2，那时看成 C 的复制）。N/d、prompt、种子、ALS、胜负口径一律不动。

**预注册攻击族（由易到难；能在特征侧完成的优先）**

1. **特征侧逐维非线性**：在 rep_perm / scale 所用的 fine_tune 特征上施加逐维单调非线性（如逐维 sigmoid / tanh / 符号保持的幂变换），可与既有置换、缩放组合。不新采集。  
2. **特征侧混合非线性**：分块旋转或分块置换后再加逐维非线性；或低秩非线性残差（特征 = 线性项 + 对隐藏坐标的非线性校正）。不新采集。  
3. **层间不一致变换**：对 `layers4` 的不同层使用不同的非线性参数（仍不新采集）。用于检查 ALS 是否依赖「各层同一线性伪装」才把攻击看穿。  
4. **权重/输入侧非线性（需新采集时单列预算）**：只有当族 1–3 已经给出明确阴性（仍 ≡ fine_tune）且导师要求加压时才启动；当前设计书不假设这些分数存在。权空间新采约 30–60 min/个 7B。

不在本实验首轮纳入：对抗微调、生成式蒸馏式攻击，以及任何会同时改 prompt 集或 N 的「增强协议」。

**读数**（每个变体预注册三条，N=128、d=8 必报）：与 fine_tune 的 similarity 差；与跨家族地板 0.254 的间隔；逐 prompt 胜负（/32）。非线性族 1–3 的 similarity **全部待跑**，不预填点估计。

**判定规则**

- **协议稳健（攻击失败）**：非线性变体 similarity 与 fine_tune 0.363 一致（差落入 seed std），胜负不崩塌。  
- **部分有效**：相对 fine_tune 明显下降，但仍高于地板、仍对跨家族可分——谱系没藏住，只是分数被打薄。必须报降幅，不得称为「突破检测」。  
- **攻击成功（检测失败）**：与地板 0.254 不可分，或逐 prompt 胜率落到与随机猜同一量级。此时记录：协议对这类非线性不稳健。  
- **无效实验**：变换后数值非有限、破坏配对、或改变了 N/d/层还声称「因为非线性」。整行作废。

**失败后怎么办（对两边都适用）**  
- 对检测方法：不能在攻击成功后事后改层、改 d、或改胜负口径来夺回 32/32，除非把「改协议」注册成新实验并在旧协议上承认失败；防御补丁另立项。  
- 对攻击方法：不能在攻击失败后改用更小 N 或更弱负例来宣称「已经更像无关模型」。N=20 若比 N=128 更「成功」，优先解释为小样本不稳定。  
- 不得把结构变体当作「攻击成功」的参照地板。

## 8. 预期表与失败标准

「预期」指方向与逻辑关系，不指编造的点估计。第 7 节判定表是各实验的主表；下表补全域停止规则。

### 8.1 实验 A（mid2）补充解读

| 观测 | 解读 | 行动 |
|---|---|---|
| 排序与 even4 一致，间隔不差或更好 | H3₁ / H-A1 方向支持；可考虑把默认层改为 mid2（须注明与 v3 全层 mid2 仍非同一集合） | 主文采用 mid2，even4 作附录消融 |
| 排序一致但独立衍生胜负明显变差 | 中段层对难正例更苛刻 | 保留 even4 为检测默认，或分「易正例 / 难正例」两套层 |
| 结构变体与 SFT 排序翻转，或跨家族升到 SFT 附近 | H3₀；不能把 mid2 当免费增益 | 默认留在 even4；调查层索引是否取错 |
| distill−control 仍约 0（方向不稳定） | 与 even4 阴性一致 | 维持 RQ2 阴性，不因换层重开蒸馏方向 |
| distill 稳定高于 control 且超出 seed std | 可能是层选择揭露了 even4 平均掉的微弱信号 | 先复核实现，再决定是否值得加 N 或加种子，仍不得丢掉 control |

### 8.2 实验 B（家族内 ROC）补充解读

| 观测 | 解读 | 行动 |
|---|---|---|
| 存在高 TPR、低 FPR 的工作点；独立衍生单独评估时工作点右移 | 与「难正例」叙述一致 | 论文报告两条工作点：含 / 不含独立衍生 |
| 正负逐 prompt 严重重叠，无稳定点 | H4₀；相对排序仍在，但单点阈值连家族内都不可用 | 放弃绝对阈值，只报告排序与胜负比 |
| 7B 阈值能直接分开 v3 的 0.5B 正负，或命题 T 成立 | 与已有「阈值不可迁移」冲突 | 在确认无泄漏前不要写「阈值可迁移」 |

### 8.3 实验 C（非线性伪装）补充解读

| 观测 | 解读 | 行动 |
|---|---|---|
| 仍 ≡ fine_tune | 协议对这类变换仍稳健（检测方法阳性） | 升级攻击或承认当前攻击弱于检测器；不要重复线性三项 |
| 降到独立衍生附近但仍高于地板 | 部分藏谱系，未变成无关模型 | 报告为「削弱但不抹除」 |
| 降到跨家族地板 | 攻击成功（攻击方法阳性） | 作为方法局限写入；下一步才考虑对抗训练或不变性增强 |
| 分数升高超过 fine_tune 很多 | 实现可疑（例如破坏配对、用错参照特征） | 先查 bug，再谈结论 |

### 8.4 全局失败（任一下一轮实验）

出现下列情形应停止加叙事、先修协议：

- 同时改了两类变量却把因果写给方法；  
- 把结构变体重新算进负例并据此宣布「7B 上 SFT 不可检」；  
- 丢掉 distillation control 或改写 0.620 vs 0.623；  
- 为 mid2 或 ROC 填写未跑出的点估计或未计算的 AUC；  
- 用英文草稿替代这份给导师的中文设计书作为唯一交付。

## 9. 给导师的阅读要点

1. v4 不是「半成功」，而是 **一条阳性主线 + 一条有结论的阴性蒸馏线**。主线：相对谱系在 7B 上可迁移（结构变体 0.53–0.56 > SFT 簇 0.357–0.365 > 衍生 0.311 > 跨家族 0.254），线性伪装被看穿，绝对阈值不可跨规模。蒸馏线：N=128、d=8 时 distill 0.620 vs control 0.623，属性「被蒸馏过」不可检。  
2. 结构变体是正例；胜负只打跨家族。旧口径不要回潮。  
3. 下一轮三件事各自独立、按 P0→P1→P2：实验 A mid2 消融（先跑，零采集）、实验 B 家族内 ROC（用已有分数标定，含可证伪命题 T）、实验 C 非线性伪装（预注册族 1–3；唯一可能需要新特征/新训练的项）。伪装仍是 RQ1c，不是附件。  
4. 「剪枝 vs SFT」相对 v3 的反转尚未做因果分离，不要在开题或论文里写成单一机制结论。  
5. 实验 C 的两种结果都有效：认出色谱系是检测阳性，打到地板是攻击阳性。
