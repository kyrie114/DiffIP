# 实验 D / E 结果

规则在跑之前写在 `实验DE设计.md`。主配置 N=128、d=8。恒等重跑与已存 even4 的最大绝对差是 1.3e-5。

| 实验 | 结论 |
|---|---|
| D 相对分数 | even4 上，用一个跨家族模型当参照、另一个当检验，SFT 和稀疏剪枝的留出工作点通过。独立衍生不过。mid2 和 N=20 不通过 |
| E 怎么打掉 | 打乱配对后分数掉到地板（0.253，5/32）。掺进 75% 的 Llama-3-8B 仍对 Qwen 有 29/32。把每维变成正态分位数仍是 32/32 |

## 实验 D

绝对分被 prompt 难度抬在一起：fine_tune 与 Qwen2.5-7B、Llama-3-8B 的逐 prompt 均值相关都是 0.956。所以实验 B 的全局阈值对不上，同一条 prompt 里的比较仍然有效。

分数改成 `sim(模型) − sim(参照)`。参照和检验各用一个负例，两个方向都做。seed 0 标定，seed 1 和 2 评估。通过线与实验 B 相同：强正例和 SFT 的留出 TPR ≥ 0.90，FPR ≤ 0.10。

even4，FPR=0 那条阈值：

| 参照 → 检验 | 阈值 | 留出强正例 TPR | 留出 SFT TPR | 留出 FPR | 留出 derivative TPR | 部署 AUC |
|---|---|---|---|---|---|---|
| Qwen → Llama-3 | 0.016 | 1.00 / 1.00 | 1.00 / 0.969 | 0.00 / 0.00 | 0.531 / 0.469 | 1.000 |
| Llama-3 → Qwen | 0.014 | 1.00 / 1.00 | 1.00 / 0.975 | 0.031 / 0.00 | 0.531 / 0.500 | 1.000 |

两个方向都通过。部署正类（稀疏剪枝 + SFT 簇）对留出负例的 AUC 是 0.9998。阈值本身很小：两个跨家族模型在同一条 prompt 上几乎一样高，只要比参照高出大约 0.015 就够。

独立衍生没有被这条阈值接住，留出 TPR 在 0.47–0.53，AUC 0.83。它比跨家族高，但高出的幅度不稳定，进不了「低误报且高召回」的工作点。实用上，这条相对分数能判官方 SFT 和同底座稀疏剪枝，不能靠同一条线把 Chinese-llama 也收成高召回正例。

边界：

- mid2 不通过。强正例仍是 1.00，SFT 留出 TPR 掉到 0.80 和 0.79。间隔在实验 A 里已经变窄，相对分数补不回 even4 的工作点。
- N=20 在 even4 上也不通过。相对阈值要配 N=128，不是小样本就能用。

## 实验 E

受害模型仍是 Llama-2-7b。掺 Llama-3 时，裁判只用 Qwen，避免把掺进去的模型拿来当负例。

| 变换 | similarity | 胜负 | 判定 |
|---|---|---|---|
| ident | 0.363±0.006 | 32/32 | 对照通过 |
| shuffle 打乱样本配对 | 0.253±0.008 | 5/32 | 配对被打掉 |
| rankgauss 逐维正态化 | 0.348±0.008 | 32/32 | 仍稳健（差 −0.015，带边是 0.018） |
| 25% Llama-3 | 0.355±0.007 | 32/32 对 Qwen | 没藏住 |
| 50% Llama-3 | 0.335±0.006 | 32/32 对 Qwen | 分数下降，谱系还在 |
| 75% Llama-3 | 0.304±0.008 | 29/32 对 Qwen | 分数下降，谱系还在 |
| 50% Chinese-llama | 0.340±0.004 | 32/32 对两个跨家族 | 分数下降，谱系还在 |

打乱配对之后，微调模型和跨家族负例的均值（0.254）重合，胜负掉到 5/32。分数用的是同一份噪声下的配对几何。配对立不住，ALS 没有别的东西可看。

反过来，边缘分布可以换掉：逐维做成标准正态之后仍然 32/32。和实验 C 的逐维单调变换是同一件事，只是更彻底。

掺入无关特征是一条剂量曲线，不是开关。到 75% 都是 Llama-3-8B 的激活，对没被掺进去的 Qwen 仍有 29/32，均值 0.304，比地板高 0.050。和同家族衍生对半混合也是 32/32。要在特征里把谱系冲掉，至少得换掉绝大部分配对样本，而不是做一层非线性或掺进一半。
