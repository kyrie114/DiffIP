## 4. 方法：同一套采集、PCA/ALS、逐 prompt 比较

**标题**：方法：同一套采集、PCA/ALS、逐 prompt 比较

**Kicker**：固定 N=128、d=8、均匀 4 层；所有实验只改一个问题

**版式**

| 区域 | 坐标 / 尺寸 | 内容 |

| 右卡片“协议” | `x=7.95, y=1.65, w=4.83, h=4.2` | 白卡片，TEAL 顶边 |
| 底部结论条 | `x=0.55, y=6.15, w=12.23, h=0.78` | LIGHTNAV |

**方法图使用说明**

- 图来自 `figs/fig1_method.png`：① 配对扰动采样（32 prompt × 3 seed sets）→ ② 两模型并行取 4 均匀层、mask 均值池化 → ③ PCA + 逐层 ALS 对齐 → similarity。
- 图里写的是 `d ∈ {8,20}`，这是方法示意；**主配置 d=8**，20 维只用于实验一的维数比较。
- 图里 `similarity = e^{-d̄}` 是定义；正文只比较同一口径下的分数，不跨口径比大小。

**图下固定量条**

固定：32 prompt（英/中/代码/数学/问答）· 3 组 seed · SCALE=2e-3 · PCA+ALS · DP 关 · 主配置 N=128 / d=8 / even4

**右卡片文字（协议）**

1. **采一样**：同一 seed 下，victim 与 suspect 的输入扰动逐位相同，特征差异归因于参数。
2. **算相似**：PCA 降维后逐层 ALS 对齐，`similarity = e^{-d̄}`，逐 prompt 平均。
3. **绝对判定**：seed 0 标定全局阈值，seed 1/2 留出；强正例与 SFT 召回 ≥0.90，FPR ≤0.10。
4. **相对判定**：`m = sim(模型) − sim(同 prompt 参照)`；参照和检验各用一个负例，另一个留出。
5. **胜负**：seed 0 上逐 prompt 对两个跨家族负例计数，32/32 是排序证据，不是阈值通过。

**底部结论条**

所有图都从 `scores*/` 与 `exp_*.json` 重算；图里不引入新口径，事后量单独标注。

**演讲备注**

方法页只讲三件事：输入扰动同 seed、特征对齐用 PCA+ALS、判定分绝对和相对两套。强调主配置是 d=8、even4；图里的 d∈{8,20} 是方法示意，不要把它当成这次主实验用了 20 维。后面所有“通过/不通过”都按同一通过线：召回 ≥0.90、FPR ≤0.10。

**数据来源**

- `figs/fig1_method.png`。
- `score.py`、`lineage.py`。
- `实验DE设计.md` 的通过线。
