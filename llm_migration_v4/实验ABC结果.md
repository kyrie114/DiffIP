# 实验 A / B / C 结果

按 `论文式实验设计书.md` 第 7 节执行。协议未改：SCALE=2e-3、三组种子、32 prompt、PCA+ALS、DP 关、主指标 N=128 d=8 的 similarity 与逐 prompt 胜负。结构变体仍是正例，胜负只对跨家族负例。蒸馏对照保留。数字来自本次脚本输出，不回写设计书里的「待跑」格。

| 实验 | 结论 |
|---|---|
| A mid2 | 排序、线性伪装、蒸馏阴性都保持。SFT 到跨家族地板的间隔从 0.109 收到 0.079，胜负没有崩。默认层留在 even4 |
| B 家族内 ROC | 绝对阈值在逐 prompt 分数上立不住。命题 T 失败：0.5B 的阈值会误拒大部分 7B SFT。蒸馏线不能共用这条阈值，distill 对 control 的 AUC=0.493 |
| C 非线性伪装 | 预注册的 9 个特征空间变换里，8 个仍落在 fine_tune 噪声带内且 32/32；符号保持平方只把分数打薄（0.344，31/32），没有藏住谱系。族 4 权空间攻击未启动 |

## 实验 A（P0）：mid2 vs even4

命令与设计书一致：`V4_LAYER_SUBSET=mid2 python score.py main`，以及蒸馏线 7 个模型。输出在 `scores_mid2/`，没有覆盖 `scores/`。mid2 = 已存储 4 个均匀层的第 1、2 个，不是 v3 全层中间 2 层。

恒等以外的主配置都是 N=128、d=8、跨 32 prompt 的三 seed 均值。胜负是 seed set 0。

| 量 | even4（设计书已核实） | mid2（本次） |
|---|---|---|
| 结构变体 | 0.528–0.559（均值 0.5415） | sparsegpt 0.477±0.010，gblm 0.442±0.002，wanda 0.430±0.003（均值 0.4500） |
| SFT 簇 | 0.357–0.365 | fine_tune 0.249±0.008，weight/rep/scale 0.249–0.250，prune_dpoff 0.245±0.007 |
| derivative_cn | 0.311±0.002 | 0.236±0.002 |
| 跨家族 | 0.254 / 0.254 | 0.170±0.008 / 0.169±0.007 |
| distill vs control | 0.620±0.003 vs 0.623±0.002 | 0.868±0.005 vs 0.870±0.005 |
| fine_tune 胜负 | 32/32 | 32/32 |
| derivative_cn 胜负 | 25/32 | 27/32 |
| 三线性伪装 | ≡ fine_tune | ≡ fine_tune（差 ≤0.001，seed std 约 0.008） |

结构变体对跨家族仍是 32/32。N=20、d=8 时 fine_tune 29/32、derivative_cn 26/32（even4 为 28/32 与 20/32）。

判定：

- H-A1 排序成立：0.43–0.48 > 0.245–0.250 > 0.236 > 0.170。没有翻转。
- H-A2 成立：三种线性伪装仍在 fine_tune 的种子波动内。
- H-A3 成立：distill − control = −0.002，落在 seed std 0.005 内；seed 0 上 distill 更高的 prompt 只有 11/32。阴性保持。两个学生仍比蒸馏线负例高约 0.026，这是同基座微调的共性，不是蒸馏信号。
- 逐 prompt 胜负没有系统性变差。

SFT 与跨家族地板的间隔从 0.109 收到 0.079。按设计书 8.1，间隔变窄就不把默认层改成 mid2。even4 继续作检测默认，mid2 只作消融。绝对分数的平移本身不单独当赢或输：主线整体下移，蒸馏线整体上移（0.62 → 0.87），两套层不能共用一条阈值。

`analysis.py` 的「结构变体 vs 跨家族」那一行是空的：它把所有 `neg_` 键跳过了，而结构变体的文件名仍带这个前缀。胜负以上面 `score.py` 的计数为准。

## 实验 B（P1）：家族内 ROC

脚本 `exp_b_roc.py`。even4 读 `scores/`，mid2 读 `scores_mid2/`，两张 ROC 不混合。样本是一个 (模型, prompt, seed) 的 similarity。正例-强 = 三个结构变体，正例-SFT = fine_tune 与三种线性伪装加 prune_dpoff，正例-难 = derivative_cn（不进部署正类），负例 = Qwen2.5-7B 与 Llama-3-8B。

预注册操作点：在 seed 0 上取阈值，seed 1 和 2 上评估。`similarity >= t` 判正。t(FPR=0) 是标定负例的最大值；t(FPR=0.05) 是标定负例的 95% 分位数。通过条件：留出 seed 上强正例与 SFT 的 TPR 都 ≥ 0.90，且 FPR ≤ 0.10。

### even4，N=128，d=8

逐 prompt 的分数很散。fine_tune 均值 0.363，但标准差 0.249（最小 0.010，最大 0.853）。两个负例均值都是 0.254，标准差同样约 0.249，最大到 0.814。高分负例集中在 prompt 23（两个负例、三个 seed 都在 0.76–0.81）。

因此一条全局阈值对不上逐 prompt 的配对比较：同一 prompt 上 fine_tune 减去两个负例的最大值，96 个 (prompt, seed) 全部为正，最小间隔 0.010，所以胜负仍是 32/32。把所有 prompt 堆在一起之后，负例的易 prompt 会盖过正例的难 prompt。

| 量 | 值 |
|---|---|
| 部署正类（强+SFT）对负例 AUC | 0.702 |
| 仅 SFT AUC | 0.645 |
| 仅 derivative_cn AUC | 0.579 |
| seed 0 的 t(FPR=0) | 0.786 |
| 留出 SFT 的 TPR | 0.0625 / 0.0625 |
| 留出 FPR | 0.000 / 0.031 |
| derivative_cn 在该阈值上的留出 TPR | 0.094 |
| 三个 seed 的负例最大值极差 | 0.050（预注册稳定线是 ≤0.02，不稳定） |

两个预注册操作点的留出检验都没有通过。N=20 的部署 AUC 是 0.699，同样不通过。mid2 上同一规则也不通过：部署 AUC 0.707，留出 SFT 的 TPR 为 0.125。

按设计书 8.2 的失败动作：放弃绝对阈值，检测继续用排序和逐 prompt 胜负。模型均值这一层仍然分开（SFT 簇 0.357–0.365，两个负例都是 0.254），但负例模型只有两个，不能把它写成通过了逐 prompt ROC。

### 命题 T（只在 even4 上）

v3 的 `pert_*`（4 均匀层，N=128，d=8，三个 seed）：fine_tune 均值 0.760，五个负例均值 0.237。逐 prompt 有重叠：fine_tune 最低 0.305，负例最高 0.624。v3 自己也不存在 TPR=1 且 FPR=0 的全局阈值。v3 的 32/32 是逐 prompt 和该 prompt 的负例比，不是一条全局阈值。fine_tune 对五个负例的池化 AUC 仍有 0.964。Youden 点是 t=0.670，v3 上 TPR=0.833、FPR=0。

搬到 v4 even4：

| 阈值 | 来源 | v4 SFT 被接受的比例 | v4 结构变体 | v4 derivative_cn | v4 负例被接受的比例 |
|---|---|---|---|---|---|
| t_mean=0.499 | 两类均值的中点 | 0.321 | 0.580 | 0.250 | 0.229 |
| t_youden=0.670 | v3 Youden | 0.154 | 0.312 | 0.188 | 0.073 |

T 失败。靠近 0.5B 正例区的绝对阈值会把大部分 7B 官方 SFT 判成「不够像基座」，同时仍误接两成以上的跨家族逐 prompt 分数。「绝对阈值不可跨规模」这次是正式计数，不再只是 0.760 对 0.363 的口头对照。

### 跨线与蒸馏误用

把 t_mean=0.499 切到蒸馏线（N=128，d=8）：学生约 76% 的逐 prompt 分数过线，四个负例约 71%–73% 也过线。整条 1B 线的尺度（学生 0.620–0.623，负例约 0.590）和主线的 0.25–0.56 不是同一把尺子。

even4 上那个不可用的 t(FPR=0)=0.786 同样切不开：学生约 31%–32% 过线，蒸馏线负例约 24%–25% 过线。

以 distill 为正、control 为负：even4 AUC=0.493，配对差 −0.003，96 对里 distill 更高的有 40 对。mid2 AUC=0.489，配对差 −0.002。没有把「被蒸馏过」做成可检。

## 实验 C（P2）：特征空间非线性伪装

脚本 `exp_c_nonlinear.py`。只改 fine_tune 特征上的变换，even4，同一 N/d 网格、同一 ALS。结果在 `scores_nl/`。对照锚是 fine_tune，不是 victim。

恒等重跑在 N=128、d=8 上与 `scores/main_fine_tune.json` 的最大绝对差是 9.5e-6。其它 N/d 上 sklearn 的 `PCA(svd_solver="auto")` 可能走随机 SVD，单点差最大约 0.012；判定不用那些格子。

预注册判定带：与 0.363 的差 ≤ 0.018 且胜负 ≥ 30/32 为协议稳健；均值落到地板 0.254 的 0.020 以内，或胜负 ≤ 20/32，为攻击成功；介于两者为部分有效。

| 变换 | 族 | similarity | 相对 0.363 | 胜负 | 判定 |
|---|---|---|---|---|---|
| ident | 对照 | 0.363±0.006 | +0.000 | 32/32 | 对照通过 |
| f1_pow05 符号保持平方根 | 1 | 0.362±0.006 | −0.001 | 32/32 | 协议稳健 |
| f1_perm_pow05 置换后再平方根 | 1 | 0.362±0.006 | −0.001 | 32/32 | 协议稳健 |
| f1_tanh | 1 | 0.371±0.007 | +0.008 | 32/32 | 协议稳健 |
| f1_scale_tanh 各向异性缩放后再 tanh | 1 | 0.353±0.006 | −0.011 | 32/32 | 协议稳健 |
| f1_pow2 符号保持平方 | 1 | 0.344±0.006 | −0.019 | 31/32 | 部分有效 |
| f2_block64_pow05 块旋转后再平方根 | 2 | 0.373±0.007 | +0.010 | 32/32 | 协议稳健 |
| f2_lowrank 秩 16 的 tanh 残差 | 2 | 0.364±0.006 | +0.000 | 32/32 | 协议稳健 |
| f3_layerpow 四层幂次 0.5/1/2/0.5 | 3 | 0.356±0.005 | −0.007 | 32/32 | 协议稳健 |
| f3_layermix 前两层 tanh、后两层平方根 | 3 | 0.362±0.005 | −0.001 | 32/32 | 协议稳健 |

没有一条落到跨家族地板，也没有一条把胜负打到随机附近。最强的是符号保持平方：激活尾巴最大约 219，平方后约 5.8e4，分数下降 0.019，刚好出了 0.018 的带，但仍比地板高 0.090，胜负 31/32。这是「削弱但不抹除」，不是突破检测。N=20 时它的胜负是 25/32，低于 N=128 的 31/32；按设计书，小 N 更「像攻击成功」先解释成小样本波动，不改判定。

tanh 与块旋转的分数略高于 fine_tune（+0.008、+0.010），仍在带内。恒等对照与已存分数一致，不是配对被破坏。

H-C 取「协议仍稳健」这一侧，外加一条部分有效。两种结果都记下了：这一组特征空间攻击没有藏住谱系。族 4（权重或输入侧、需要重新采集）按设计书要等族 1–3 全部仍 ≡ fine_tune 且导师要求加压才启动。这里有一条部分有效，也没有单独的加压要求，所以没有新采 7B。
