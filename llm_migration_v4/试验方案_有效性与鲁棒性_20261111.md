# 试验方案：有效性与鲁棒性两模块

2026-11-11。规则在跑之前写死。模型只从机子 1 的本地库 `/data/luo_lixuan/llms` 取，清单以 2026-11-07 核对的本目录 `本地模型清单.md` 为准。跑之前再核对该目录是否仍在、分片是否还齐。

本方案把已完成的 7B 主实验、0.5B 与 REEF 的对照，以及尚未补跑的模型，收成论文里两个并列模块。评测对齐现有论文已经使用的数据集：主要是各篇共用的模型盘；需要文本的方法沿用其官方探针，不另建训练或评测语料，也不改成在公开下游任务上算准确率。理由和对照范围见下一节。

和 2026-11-10 的「DiffIP 与 REEF 同等对照」方案兼容：7B 上要补的 REEF 仍按那份官方设置来跑，本文件只把模型按两个模块重新分组，并补上要新采的 DiffIP 名单。不改 DiffIP 默认设定，不把对照或盘面扩大写成新的消融。


## 与现有论文数据集的对齐

使用现有、已被正式论文采用的评测对象，比自建一套新语料更有道理，也更便于和已有方法对照。本方案采用这一原则。需要对齐的是这些论文里实际使用的数据集，不能把评测改成在 MMLU、GSM8K、WikiText 上算下游准确率——那些不是指纹或谱系验证的官方设定。

在 REEF、HuRef、Independence Tests、GhostSpec、AWM 里，所谓数据集主要是模型对：一个受害模型、若干同谱系衍生模型、若干无关模型。实验单位是模型，不是另建的训练或测试语料。各篇用到文本时，也只是引出表示的探针，不是任务分数：

- Independence Tests：评测盘是模型对（含以 Llama-2-7B 为一方的多组对照）。需要激活时才喂文本：受约束设定从词表随机抽 4096 个 token；不受约束的匹配检验用 WikiText-103 做一次前向，取出 MLP 激活。Dolma v1_7 只用于他们自己训练两套独立初始化的 OLMo，检查会不会误判，不是评测集。
- GhostSpec：完全不需要文本，对注意力权重乘积做奇异值分解。文中的数据集是以 Llama-2-7B 和 Mistral-7B 为主的 55 对模型（第 5.1 节，完整名单见附录表 9）。
- AWM：只看词嵌入和查询、键权重。文中的 150 对数据集是 60 对同源加 90 对无关模型。附录里的 GSM8K、金融语料等是那些衍生模型当初怎么训出来的，不是指纹评测集。
- REEF：同样以模型对为评测盘；表示取自 TruthfulQA 前 200 条，用来算第 18 层线性中心化核对齐，不在该语料上报告问答准确率。
- HuRef：基于权重，评测盘同样是模型对，不依赖公开下游语料。

因此，本方案与现有论文对齐的是模型盘，并优先采用各篇都常用、且本地已经有的模型：受害模型固定为 Llama-2-7B；有效性正例加入与多篇重叠的 `vicuna-7b-v1.5`；无关模型采用已扩盘的 5 个，并预留 `open_llama_7b`、`opt-6.7b`、`pythia-6.9b`、`bloom-7b1` 作追加检查；鲁棒性正例采用同底座剪枝，以及论文中常见的 Sheared-LLaMA；继续预训练压力测试采用 REEF 表 1 中的 `CodeLlama-7b-hf`、`WizardMath-7B-V1.0`、`llemma_7b`。本地没有的论文模型不新下载，也不拿近邻版本冒充。

探针文本各用各方法已经公开的设定，不强行改成同一批句子：DiffIP 沿用已经冻结的 32 条提示，写在 `llm_migration_v4/common.py` 的 `PROMPTS` 里，不在这些提示上训练；对照 REEF 时，REEF 仍用官方的 TruthfulQA 前 200 条。比的是两套完整方法在同一组权重上的判别结果。本轮不把 DiffIP 的提示换成 WikiText-103，那会改已经冻结的协议，也不在 WikiText、TruthfulQA、MMLU 或 GSM8K 上报告准确率当作指纹指标。

## 要回答的问题

受害模型固定为 Llama-2-7B（`Llama-2-7b-hf`）。判定规则全程不变。

1. **有效性**：在常见、已发布的后续开发（主要是官方或第三方微调）上，方法能不能认出同谱系，同时不把无关模型误判成衍生模型。
2. **鲁棒性**：在同一受害模型、同一判定规则下，对更强或带对抗性质的变换（剪枝与层删除、置换、缩放，以及更重的继续预训练）还能不能维持识别；按变换类型分别报告，不预先当成已经通过。

0.5B 上已完成的官方 REEF 对照保留在有效性模块里引用，不得与 7B 数字放进同一张表。蒸馏和纯接口黑盒本轮不做通过项。消融（主成分维数、层取样、扰动次数）已经做完，本轮不再重跑。

## 冻结的协议

两种方法都只读权重，不训练、不改参数。DiffIP 与主实验完全相同，不得改动：

- 配对扰动：\(\tilde{e}_i = e + \sigma\varepsilon_i\)，\(\sigma = 2\times 10^{-3}\)，两侧使用同一噪声序列与相同顺序；每条提示 128 个样本（1 个干净嵌入加 127 份扰动嵌入）。
- 32 条提示写在 `llm_migration_v4/common.py` 的 `PROMPTS` 里，3 组种子 `{123, 1123, 2123}`，不得另换提示集。
- 提取 token 平均隐藏状态。层数 32 的 Llama 结构取第 0、10、21、31 层；层数不同的模型按 `even_layers(总层数, 4)` 均匀取 4 层，并在表注写明层号。本轮将遇到的层号预先写死：Qwen2.5-7B（28 层）取第 0、9、18、27 层；Sheared-LLaMA-1.3B 三份（24 层）取第 0、8、15、23 层；bloom-7b1（30 层）取第 0、10、19、29 层。其余 32 层模型仍取第 0、10、21、31 层。
- 主成分分析降至 8 维，逐层交替最小二乘（正交旋转、逐维缩放、平移），各层残差平均后 \(\mathrm{sim} = e^{-\bar{d}}\)。
- 判定：同一条提示上 \(\Delta_p(M) = \mathrm{sim}_p(M,V) - \mathrm{sim}_p(R,V)\)。阈值取种子 0 上留出无关模型在 32 条提示上的最大差值，于种子 1、2 上检验。通过标准不变：官方对话微调及其已登记的派生变换，加上三种稀疏剪枝，留出召回 \(\ge 0.90\)，留出无关模型误报 \(\le 0.10\)，两个参照方向都要满足。中文衍生版 `Chinese-llama-2-7b` 只附带报告，不参与通过判定。`win_counts()` 不是通过标准。
- 本轮正式无关参照集沿用已经扩盘后的 5 个模型：`Qwen2.5-7B`、`Meta-Llama-3-8B`、`llama-7b-hf`（第一代 Llama）、`Baichuan-7B`、`mpt-7b`。**不改已经冻结的阈值。** 后面若再补 `open_llama_7b`、`opt-6.7b`、`pythia-6.9b`、`bloom-7b1`，只作为追加误报检查，对照这套冻结阈值报告，不得把它们纳入校准后再改通过线。
- `internlm2-7b` 深层激活会出现非有限值，隔离，不再采集、不进任何表。

REEF 协议与 2026-11-10 方案相同：TruthfulQA 前 200 条、固定顺序、不用聊天模板、不截断；各层最后一个 token 的隐藏状态；主指标为第 18 层（零基索引 18）的线性中心化核对齐，预处理为中心化加逐特征标准化。层数不足 19 的模型取该模型各层与受害模型第 18 层的最大中心化核对齐，并在表注写明。主表只报第 18 层线性中心化核对齐。不得把论文表 1 的着色切分当成通过标准。REEF 一律以同一份本地权重重跑为准，论文数字只作旁注。两种方法的提示集本来就不同，比的是两套完整方法在同一组权重上的判别结果。

## 执行步骤

代码入口在 `llm_migration_v4/`。先改名册，再采集，再打分。新模型必须先写进 `common.py` 的注册表（建议用上表的内部名），`collect.py` 和 `score.py` 才能按名字取路径。采集命令在名称注册之后才能跑。

1. 核验上表各目录仍在 `/data/luo_lixuan/llms`，分片齐全；核验已有特征和 REEF 激活缓存对应的是同一路径下的同一份权重，否则重提。
2. 在 `common.py` 注册本轮新名字：`pos_vicuna`、六个 Sheared 正例、`cpt_codellama`、`cpt_wizardmath`、`cpt_llemma`；可选追加无关模型若进入第二优先，再注册。不要复用蒸馏线里的 `neg_sheared_1_3b` 这个负例名。
3. 按模块 A 补跑缺的 DiffIP 与 REEF。DiffIP 采集与打分示例（注册完成后）：

```bash
cd llm_migration_v4
python collect.py main pos_vicuna
python score.py main pos_vicuna
```

4. 按模块 B 补跑三个稀疏剪枝的 REEF，以及 Sheared 全套、三项继续预训练的 DiffIP（CodeLlama 的 REEF 一并补）。`WizardMath-7B-V1.0`、`llemma_7b` 体积较大，单独安排显存，不要和 7B 半精度模型抢同一张卡硬并行。
5. 用已经冻结的阈值汇总两张主表。核对没有把 Qwen1.5、论文里的参数余弦、WizardMath-7B-1.1、`internlm2-7b`，或把 Sheared 当无关模型混进表里。
6. 第一优先全部完成并检查无误后，再决定是否跑追加无关模型，或另写 HuRef / 计时的补充方案。
