# LLM 指纹方法对比与实验笔记

> ⚠️ **DiffIP→LLM 实验请以 [`docs/LLM迁移实验导读.md`](../docs/LLM迁移实验导读.md) 为准。**  
> 本笔记整理自多轮讨论，混入了「三代指纹」与其它路线；下文「旧方法 vs collector/campaign 新方法」把严格重跑误写成「余弦聚合」，**不准确**。  
> 正确对照：另一台机 = `llm_transfer/`（collector + DiffIPMetric）；本 bot 主线 = `llm_migration_v2/`→`llm_migration_v3/`（ALS + 平均 L2，不是余弦）。`llm_migration/` 最早版本用 margin，已否。

## 一、三代指纹方法的总览（按"拿什么当指纹"划分）

| | 第一代：权重空间（白盒） | 第二代：输出空间（黑盒） | 第三代：内部表示（灰盒，当前主线） |
|---|---|---|---|
| **指纹载体** | 权重增量 ΔW、敏感度向量（扰动权重看损失变化） | 输出文本 / softmax 概率 / 对固定探针句的回复 | 中间层隐状态（hook 抓 decoder 层，句子级平均向量） |
| **访问要求** | 完整权重，必须同架构可比 | 只要 API，最宽松 | 能 forward、能挂 hook，不用看权重 |
| **计算成本** | 高（反复前向+反传或逐层扰动） | 低 | 中（蒸馏/采集一次 + hook 抓取） |
| **架构限制** | 强：ΔW 形状必须对齐，跨架构无法直接比 | 无 | 无（跨架构可用 CKA / 余弦比较） |
| **抗微调/量化** | 差：对微调极敏感，量化一次就漂移 | 中：输出分布较稳，但可被 prompt 洗掉 | 中：中间层比输出稳，但对剪枝仍敏感 |
| **主要风险** | 跨架构不可比是硬伤 | 表层模仿（蒸馏模型）也能骗过 | 中间层区分力不足 → 误报风险 |

### 核心认识（对话中达成的理解）

1. **三代方法的演进逻辑**：从"问权重"→"问输出"→"问中间层"。
   访问门槛逐级降低、适用面逐级变宽，**代价是指纹可分性逐级变差**，
   需要靠后处理（容差、分块哈希、分层校准）补回来。
2. **场景选择**：
   - 只有 API → 只能用第二/三代；
   - 有完整权重且同架构 → 第一代反而最准；
   - 跨架构比对 → 第三代是唯一选择。
3. **信息丰富的另一面是噪声也多**：中间层既有模型个体特征，也有大量任务通用
   表征，所以需要分层测量（tier1/2/3）定位哪一段信号真正可用。

## 二、本仓库两条路线的区别（机制层面，不是版本迭代）

> **更正（导读为准）**：下面把「新方法」写成 collector/campaign **余弦**，与事实不符。严格重跑（`llm_migration_v3`）的判定是 DiffIP 的 **ALS mean L2**；`llm_transfer` 用的是 **DiffIPMetric**。请勿再按本节省略理解主实验。

### 旧方法：`llm_migration/`（官方 DiffIPMetric 直接迁移到 LLM）

- **机制**：保持 DiffIP 原始协议（faithful）——
  对同一 seed 构造**扰动云**，把扩散模型的"时间步 → 层"轴替换成 LLM 的"层"轴，
  多种子 → 多条 prompt；
  对齐手段是 PCA + Procrustes + DP 谱对齐，逐层比较表示几何。
- **要求**：需要控制扰动（白盒程度高），逐层、逐 seed 跑，成本高。
- **实测结论**：天花板很低，曾得出"相似度上限 ~0.18"的悲观结论。

### 新方法：collector / campaign（本次会话新推）

- **机制**：把 LLM 包装成"可被 DiffIP 打指纹的对象"——
  `LLMRepresentationCollector` 三层结构（截取 decoder 层、注册 hook、按句子聚合
  平均隐状态），campaign 批量采集多条 prompt；
  相似度 = 共享 prompt 下表示响应的余弦，**逐 prompt 评分后聚合**（均值/中位数），
  不依赖扰动云对齐，层选择做了尺度扫描（L=4 层，dims=8，N=128）。
- **配套**：剪枝容差、分块哈希、ROC 阈值标定、tier1/2/3 分层测量。

### 机制区别（回答"是不是只是版本不同"）

**是机制不同，不只是调参**：

| 维度 | 旧（llm_migration） | 新（collector/campaign） |
|---|---|---|
| 比较对象 | 同扰动下逐层表示**几何**（PCA/Procrustes 对齐） | 共享探针下表示**响应**（余弦 + 聚合） |
| 是否需要扰动云 | 需要（协议核心） | 不需要 |
| 轴替换 | 时间步→层，种子→prompt | 无此概念，直接逐 prompt 独立评分 |
| 评分粒度 | 逐层对齐距离 | 逐 prompt 距离 → 聚合 → similarity |
| 标定方式 | 无（沿用原协议） | ROC 扫描（正例对 16 / 负例对 32，AUC + 阈值） |

### 实验数字（实测）

- **剪枝自相似**（新方法指纹稳定性）：剪枝率 1% / 3% / 5% →
  自相似 0.98 / 0.94 / 0.90。结论：指纹必须配剪枝容差，不能裸用余弦。
- **CKA 基线**：跨家族中位数 0.5266；LLaMA-3 vs Qwen 相关性偏高，
  直接卡阈值有误报风险 → 需要分块哈希 + 分层校准。
- **ROC 标定设计**：2 个正例对（SmolLM2-135M↔Instruct、Qwen2.5-0.5B↔Instruct，
  均为真实 SFT）× 4 个负例对（SmolLM2 系 × Qwen 系交叉），每对 8 条 prompt，
  48 个样本点（16 正 / 32 负），阈值扫描 + AUC。
- **v3 结果（方案 a：扰动采样，DiffIP-faithful 协议，N=128，dims=8）**：
  victim 为 Qwen2.5-0.5B 时，真实配对的相似度高于全部 5 个负例对照——
  **推翻了旧方法"天花板 ~0.18"的悲观结论**，最终判定：这条线跑通了。

## 四、collector / campaign 方法详解（全流程，每步含"为什么"）

### 4.1 表示采集器 `LLMRepresentationCollector`——把 LLM 变成可指纹对象

**是什么**：DiffIP 采样协议到 LLM 的翻译桥梁，整个迁移的基石。

**怎么做**（三层结构）：
1. **截取**：在模型 decoder 层上注册 forward hook，模型推理时把每一层的
   hidden state 截下来（一句话从第 1 层算到第 30 层，每层都留一份）。
2. **池化**：逐层做 attention-mask 加权 mean pooling，一句话过一遍模型
   → 每层一个向量。多条 prompt 批量跑 → `[L, N, D]`（L=层数，N=样本数，
   D=隐维度）。
3. **同构化**：`[L, N, D]` 与 `DiffIPMetric` 期望的 `[T, N, D]`（时间步×样本×维度）
   **完全同构**——这就是"轴替换"落地的位置：层对应时间步。

**为什么**：DiffIP 的核心假设是"同一对象在扰动下的表示几何具有稳定性"。
要把它用在 LLM 上，必须先让 LLM 产出同构的表示张量，且这个张量对
victim 和 suspect **用完全相同的方式**采集，否则后续对齐无从谈起。

**三种采样模式**：perturbation（同 prompt 在输入 embedding 上加高斯噪声，
**victim 与 suspect 必须配对种子**——对应扩散方法"seed order must remain
consistent"的硬性要求）/ prompts / hybrid。

### 4.2 判定核心 `DiffIPMetric.compare()`

独立 PCA-20 降维 → 逐步 Procrustes 对齐（带回退）→ DP 时序对齐。
支持**跨维度、跨层数**的模型对（靠独立 PCA + DP 兜住，不要求两模型隐维相同）。

### 4.3 尺度扫描——发现并修复协议 bug（本方法最关键的一步）

**做了什么**：扫描扰动强度 perturbation_scale，看 similarity 响应曲线。

**发现**：未配对种子时，距离被采样噪声主导，曲线呈 **0/1 悬崖**——
这是"错误协议的假象"，不是方法本身的问题。

**修复后**：perturbation 曲线单调——噪声 ≤3e-3 时 similarity≈1.0（自相似），
无关代理 ≈0.50 → 定下工作点 **`perturbation_scale=2e-3, seed=123`**。

**为什么重要**：如果不做这一步，后面所有实验都在错误的协议上跑，
结论全部无效。

### 4.4 真实模型对验证（排序正确性）

- SmolLM2-135M 自比 **1.000**
- ↔ Instruct（真实 SFT，正例）**0.505**
- ↔ Qwen2.5-0.5B（跨家族，负例）**0.323**

排序正确（自比 > SFT > 跨家族），且跨维度、跨层数模型对都能跑通。

### 4.5 消融实验（找上限，诚实记录否定结果）

| 实验 | 结果 |
|---|---|
| 层/样本消融 | 在该配置下裕度天花板 ~0.18；N=8 即饱和，N=16 正例崩塌 |
| 混合采样 | **否定**：异质 prompt 混入同一样本轴会摧毁配对 Procrustes 假设，全部归零 |
| 分 prompt 聚合 | 只降方差、不提可分性 |

### 4.6 ROC 标定（阈值能否跨家族）

- 设计：2 个正例对（SmolLM2-135M↔Instruct、Qwen2.5-0.5B↔Instruct）+
  4 个负例对（SmolLM2 系 × Qwen 系交叉），每对 8 条 prompt，48 个样本点
  （16 正 / 32 负），阈值扫描 + AUC。
- **结果：AUC 0.678**；最佳工作点（Youden J=0.375）距离 ≤ 0.737 判同源
  （TPR=0.50, FPR=0.125）。
- **关键发现：全局阈值不可迁移**。距离的绝对尺度是**家族依赖**的：
  Qwen 正例对 0.10~0.74（完美可分），但 SmolLM2 正例对 1.03~4.02
  （被全局阈值误判为异源）——SmolLM2-Instruct 的 SFT 对表示的改写幅度
  与跨家族差异同量级。**要实用需家族内相对标定**（如用底座无关参照模型
  归一化距离），这是明确的方法局限。

### 4.7 蒸馏验证线（防"表层模仿"欺骗）

**做了什么**：用 GPT-2 当教师，两阶段训练学生——阶段 1 在 Alpaca 子集上做
隐状态 + KD 蒸馏，阶段 2 用 victim 的 hook 表示做对照（control 学生只做
KD、不做隐状态对齐）。训练数据 `data/teacher_data.json`（约 1.5MB，已入库）。

**结果（v2，诚实版）**：
- 蒸馏强度确实达成（留出集）：教师回答 NLL/字节 0.348→**0.256**；
  top-1 0.601→**0.675**；ROUGE-L 0.123→**0.260**（对照学生更差）。
- **但指纹 margin 对基座+对照为负**：DiffIP20 −0.0003；CKA_plain −0.004；
  CKA_std −0.002——且同家族 Qwen2-0.5B 的 DiffIP 相似度（0.952）反高于
  蒸馏学生（0.918）。
- **结论**：行为上学得像 ≠ 表示上像。蒸馏学生的输出模仿没有在
  DiffIP/CKA 指纹上留下正信号——这既是负面结果，也反过来支持了
  "中间层指纹抓的是深层血统而非表层行为"的方法论立场。

### 4.8 v2 / v3 修正（配置突破，推翻悲观结论）

- 上述"天花板 ~0.18"是**配置受限的**（victim 135M、8 条 prompt、N 小）。
- 后续用更严格协议（**32 prompts、N=128、dims=8**）在 Qwen2.5-0.5B victim 上
  做到 **裕度 0.52、32/32 全可分**——瓶颈在配置不在方法。
- v3（方案 a：扰动采样，DiffIP-faithful 协议，N=128，dims=8）：
  真实配对相似度**高于全部 5 个负例对照**，最终判定整条线跑通。
- 归属说明（诚实）：天花板修正来自后续 v2/v3 的更严格协议实验。

### 4.9 支撑组件（实用化的必要件）

- **剪枝容差**：剪枝率 1%/3%/5% → 自相似 0.98/0.94/0.90，
  指纹必须配容差，不能裸用。
- **CKA 对照组**：CKA_plain / CKA_std 与 DiffIP 并行计算作为交叉验证
  （v2 蒸馏线中三者 margin 一致为负，交叉确认）。
- **分块哈希**：为跨家族阈值问题准备的补偿方案。

### 4.10 campaign 最终结论（存档）

1. DiffIP 结构可迁移到 LLM（排序正确、跨维度/跨层数 DP 对齐可用）；
2. 旧配置下裕度天花板 ~0.18，根因是配对 Procrustes 假设在异模型层云上
   只近似成立；**更严格协议下突破至 0.52**；
3. 采样策略（尺度/层数/样本数/混合/分 prompt）中混合采样被否定，
   其余在正确配置下有效；
4. ROC：AUC 0.678，全局阈值跨家族不可迁移，实用需家族内相对标定；
5. 蒸馏学生行为相似但指纹无正信号——中间层指纹抓的是深层血统。
