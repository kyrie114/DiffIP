# 文献协议实验：真实社区衍生模型 + 难负例 + 置换检验 + 蒸馏换信号

日期：2026-10-30（Asia/Shanghai）。代码：`lit_models.py`（模型表）、`collect.py`、`score.py`、`distill_signal.py`；
数字：`results.json`、`results_distill_signal.json`、`score.log`、`distill_signal.log`。全部 CPU，未训练任何模型。

## 1. 每个实验参照哪篇论文的做法

| 实验 | 参照 | 做法 |
|---|---|---|
| A. 公开生态真实衍生模型当正例 | **REEF（ICLR 2025, CCF-A）** Table 1：用 Llama-2-7b 的真实社区后代（Vicuna、WizardMath、CodeLlama 500B token、Llemma 700B token 等）；**HuRef（NeurIPS 2024, CCF-A）** §5.1.1/Table 2–3：每个基座取流行后代，覆盖 SFT/RLHF/继续预训练 | 从 HF `base_model:finetune/merge` 列表里选 9 个 Qwen2.5-0.5B 后代 |
| B. 同厂商、不同预训练的难负例 | HuRef §5.1.2（28 个独立训练模型）；REEF 的 unrelated 组 | 新增 Qwen2-0.5B-Instruct、Qwen3-0.6B-Base |
| C. 基座归属（谁是你的基座） | HuRef §5.1.3（51 个后代对 18 个候选基座取最高 ICS） | 每个模型再对 Qwen2-0.5B、SmolLM2-360M 两个候选基座打分 |
| D. 固定阈值 → 假设检验 | 单侧置换检验（32 个可疑提示词分数 vs 负例池，20000 次打乱）；与 DeepJudge（IEEE S&P 2022）用多指标+阈值投票的做法相对照 | 每行给 perm p |
| E. 蒸馏换信号 | 输出分布 / 教师偏好类思路（比较输出而非隐藏几何） | 见 §5 |

协议与 v3 主表完全一致：32 提示词、3 组种子、N=128、σ=2e-3、4 个均匀层、均值池化、fp32、PCA 8 维、ALS Q/S/h，sim=exp(−mean d)。gap/AUC/wins/perm p 用种子组 0。
**base5** = 原 5 个负例；**ext7** = base5 + 2 个新难负例。

## 5. 分析（含失败）

1. **没有假阳性。** 同厂商的难负例 Qwen2-0.5B-Instruct 和 Qwen3-0.6B-Base 都落在负例底噪（0.143），p=0.50。"同家族、不同预训练"能被正确判为无关。
2. **SFT、权重编辑、合并类后代全部检出**（7/7 的 p=5e-05，AUC 0.87–1.00）。相似度随偏离程度下降：nuextract 0.98 → 跨语言 SFT 的 vikhr 0.43。
3. **重大失败：继续预训练。** Qwen2.5-Coder-0.5B 和 Coder-Instruct 跌到负例水平（p≈0.4）。REEF 论文 Table 1 报告 CodeLlama（500B token）的 CKA 仍为 0.99，**我们的方法在这一类上明显不如 REEF 的报告**。这是本批最重要的负结果。
4. **r1_draft 也失败**（0.144，完全等于底噪）。可能原因（未核实）：该模型的说明是为 R1 投机解码做的 draft，可能改过词表/嵌入或训练量很大。需要看其 config/tokenizer 才能下结论。
5. **基座归属实验（HuRef §5.1.3 式）无效，不能用。** 以 Qwen2-0.5B 为参考时，**所有**模型（包括 GPT-2、Pythia）的 sim 都≈0.72；以 SmolLM2-360M 为参考时都≈0.016。只有真正的后代 Qwen2-0.5B-Instruct 升到 0.986。也就是说，sim 的**绝对值取决于参考模型本身**（底噪随参考模型变），跨参考模型取 argmax 没有意义。表里那些 argmax 一列（如 neg_gpt2→qwen2_0.5b）是这个伪影，**不是归属结论**。正确做法是对每个候选基座各自用负例做标准化（z 分数或各自的置换 p），留作下一步。
6. 固定阈值改成置换 p 以后，结论更清楚：p 要么是 5e-05，要么≥0.35，中间没有模糊地带。

## 6. 蒸馏：换信号（输出分布），CPU，复用既有学生

教师为 Qwen2.5-0.5B-Instruct。复用 `/workspace/papers/exp_distill_v2/ckpt/student_{distill,control}`：两者都是 SmolLM2-135M，distill 在教师回答上做 SFT，control 在 Alpaca 原文上训练，预算相同。数据用 120 条**训练未见**的留出指令。

- **S1（扰动云上的下一 token 分布）**：在回答起始位置，对各模型自己的嵌入加 v3 扰动（seed 123、σ=2e-3、16 个样本）。把两边分布映射到解码字符串完全相同的共享词表上，算 1−JS/ln2，再对 16 个样本取平均。
- **S2（教师偏好）**：教师自己的留出回答在可疑模型下的每字节 NLL，取负号（与分词器无关）。

| 模型 | S1 均值 | top-1 一致率 | 教师回答 NLL/byte |
|---|---:|---:|---:|
| student_distill | **0.609** | 0.409 | **0.261** |
| student_control | 0.588 | 0.469 | 0.407 |
| base_smollm2_135m | 0.305 | 0.017 | 0.369 |
| neg_smollm2_360m | 0.480 | 0.183 | 0.317 |
| neg_gpt2 | 0.002 | 0.000 | 0.584 |
| neg_pythia_160m | 0.213 | 0.000 | 0.521 |
| neg_qwen2_0.5b | 0.561 | 0.405 | 0.275 |

| 检测（正例=student_distill） | gap | AUC vs 其余全部 | AUC vs control | 胜 control | 胜全部 |
|---|---:|---:|---:|---:|---:|
| S1 扰动云分布 | +0.021 | 0.764 | **0.523** | 61/120 | 43/120 |
| S2 教师 NLL | +0.014 | 0.822 | **0.891** | 118/120 | 69/120 |

结论：
- **S1 仍然失败**：相对关键对照 control，AUC 只有 0.52，约等于瞎猜。S1 测到的是"有没有学过指令格式"，不是"学过谁"。
- **S2 有效**：对 control 的 AUC 0.89，120 条里赢 118 条。但它对同厂商无关模型 Qwen2-0.5B 的差距很小（0.261 vs 0.275，gap 仅 +0.014，逐条只赢 69/120）。教师数据本身就带有 Qwen 风格，所以 S2 本质上是**黑盒输出类**信号，不再是 DiffIP 白盒几何。
- 以前用隐藏几何的 AUC≈0.50（`improve/蒸馏鲁棒性.md`）。现在换到输出信号，相对 control 能分开，相对同家族无关模型则只是勉强分开。只有一对学生、一个教师，样本太少，不能推广。真正的蒸馏实验（多教师、多强度、logit 级 KD）仍需要 GPU。

## 7. 偏差与未做

- **更大族系（Qwen2.5-1.5B 与其 Instruct）没做**：fp32 约 6GB，加上采集开销，超出本机当时的可用内存（约 2.4GB）。
- 正例只有 9 个，远少于 HuRef 的 51 个。衍生关系只取自模型卡，未逐个核实。
- 基座归属实验因 §5.5 的标准化问题作废，只保留原始数字。
- 没有复现 REEF 在同一批社区模型上的分数，所以"REEF 在 Coder 上更好"引用的是它论文里 Llama 上的结果，不是本机实测。
