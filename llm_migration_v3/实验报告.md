# llm_migration_v3 实验报告：严格按 DiffIP 采样（大数定律）重跑

Victim 固定为 `Qwen/Qwen2.5-0.5B`。DP 默认关闭，只在第 5 节剪枝中按官方代码打开。主指标是 DiffIP 的逐层 ALS 平均 L2 距离（QSX−h），similarity = exp(−Σd/L)。不用 margin 作判定。所有数字都来自本目录下的脚本和 `scores/*.json`，可以复现。

## 1. DiffIP 原文怎么采样（引自 /workspace/papers/diffip.txt）

- 第 263–274 行："To estimate X's behavior for a given input z, we generate N diverse random seeds to trigger the suspect diffusion model Fs and collect N responses from it, where N is a hyperparameter. … using the same N seeds to trigger the victim diffusion model Fv … we can estimate the behavior of X and Y based on the law of large numbers."
- 第 1046–1049 行："we use 200 prompts from PartiPrompts … and report the average similarity score among these 200 inputs as the final result. For each prompt, we perform sampling with 20 different random seeds (i.e., N = 20)"
- 第 903 行："for a given input (text prompt), we run both the suspect and victim diffusion models with N different random seeds"
- 官方 README："`N` is the shared number of random seeds … the seed order must remain consistent"。也就是说，样本必须按 seed 配对，ALS 拟合的就是配对矩阵 X_sample ↔ Y_sample。

由此可以确定原协议的要点：
1. 每个输入（prompt）单独做一份 N 样本指纹，单独打分，最后对 prompt 取平均；不同 prompt 之间不混合。
2. 论文用 N=20。原文没有给出 N 应该多大才算满足 LLN，只说 N 是超参数。
3. suspect 和 victim 使用同一组 seed，样本一一配对。

## 2. 映射到 LLM

扩散模型中，seed 决定初始噪声 x_T。它是网络的输入噪声，网络本身是确定性的，同一个 seed 在两个模型里给出可以对应的样本。

- 方案 (a)：输入 embedding 加配对种子扰动（当前方法）。seed 决定加到 prompt embedding 上的高斯噪声 ε_i（尺度 2e-3），网络确定性地传播这个噪声。它对应"seed→输入噪声→确定性网络"这一结构，并且 suspect/victim 在同一 seed 下的样本严格配对：同为 896 维的 Qwen 系模型噪声完全相同，其他模型维度不同时，用的是同一个生成器序列。
- 方案 (b)：随机解码。seed 生成均匀随机数 u[i,t]，两个模型都用逆 CDF 从各自温度为 1 的分布里采 16 个 token。这对应"F 是模型自身的随机分布"，但配对很弱：不同模型在同一个 u 下，一旦某个 token 不同，后续就完全分叉。
- 结论：(a) 最符合"同 seed 配对，样本可以一一对应"这一要求，所以定为主方案。(b) 作为对照一并在跑（见第 6 节）。

批量实现 `common.py` 与官方 `LLMRepresentationCollector` 做过数值等价检查（`test_equivalence.py`）：max|diff| = 7.1e-5，属于 float32 误差，与 v2 缓存的 victim.npy 一致。另一个旁证：GPT2、prompt 0、seed 123、N=8、8 维的分数为 0.2452，与 v2 相同。

## 3. 设置

- 32 个 prompt：英文 7、中文 6、代码 6、数学 6、问答 7，见 `common.py`。每个 prompt 单独指纹、单独打分。
- 3 个 seed set：123、1123、2123。每个 set 采 128 个样本，N<128 时取前 N 个。这与用该 seed、n_samples=N 调官方采集器的结果逐位相同。
- N ∈ {8, 16, 20, 32, 64, 128}，dims ∈ {8, 20}。所有组合都满足 dims ≤ 4N−1 = 31，代码里有 assert。
- 层：每个模型 4 个均匀层；attention-mask 均值池化。
- 衍生模型：
  - 微调（Instruct）；
  - 权重置换（实际跑了置换后的模型，输入为 (E+ε)P）；
  - 表征列置换；
  - 各向异性缩放（s~U[0.25,4]）；
  - 剪枝（删去第 5/9/14/18 层，剩 20 层）。
- 负例：SmolLM2-135M、SmolLM2-360M、GPT2、Pythia-160M、Qwen2-0.5B（同家族不同模型）。

- PCA 秩不是原因：所有组合都满足 dims ≤ 4N−1。
- 扰动尺度扫描（D4）在 `diagnose.py` 里已经写好，但还没跑（排在解码采样之后），**待补**。
