日期：2026-10-29（Asia/Shanghai）。  
代码：`exp3_distill_robust.py`；数字：`results_exp3_distill.json`。  
**本机未新开蒸馏训练**（无 GPU）；复用既有  
`/workspace/papers/exp_distill_v2/ckpt/student_{distill,control}`（序列级 KD，教师 Qwen2.5-0.5B-Instruct，学生 SmolLM2-135M；强度见 `llm_migration/exp_distill_v2/实验报告.md`）。

## 1. 协议

| 项 | 设定 |
|---|---|
| 配对扰动 | scale=2e-3，seed=123，N=64，32 个 v3 提示词 |
| 采集层 | 4 均匀层；打分用 **middle2=[1,2]** |
| DiffIP | PCA dims=8 + 逐层 ALS，sim=`exp(−Σd/L′)`（跨维 OK） |
| 余弦 / CKA | **仅同维**；异维记 n/a |
| 大样本 QSh | 同维；前 16 提示校准（M=16×64=1024/层），后 16 留出；全维与 PCA-32 |

两个 victim 面板：

- **A `vs_teacher`**：victim = 教师（蒸馏来源，跨架构跨词表）
- **B `vs_base`**：victim = SmolLM2-135M 基座（学生初始化；蒸馏 ≈ 在教师文本上 SFT）

正例：`student_distill`。关键对照：`student_control`（同基座、同预算，Alpaca 原文而非教师回答）。另加无关负例。

检测（distill vs 全部其它）：

| 指标 | 值 |
|---|---:|
| gap = mean(distill)−max(neg mean) | **≈ +0.00002** |
| AUC vs 全部负例 | **0.504** |
| wins vs control（逐 prompt） | 19/32 |
| DiffIP AUC distill vs control only | **0.512** |

**结论 A**：在配对扰动 + middle2 DiffIP 下，**认不出「蒸馏自该教师」的学生**；分数与对照学生、甚至未蒸馏基座贴在一起。与 `exp_distill_v2` 旧报告一致，并排除了「只是旧 margin 协议不好」的解释——换 v3/middle2 协议后仍失败。跨维导致余弦/CKA/QSh 无法作对照。

## 3. 面板 B：相对基座（同维）— **仍分不开 distill vs control**

| suspect | DiffIP | 余弦 | CKA | QSh 全维留出 sim | QSh PCA32 |
|---|---:|---:|---:|---:|---:|
| student_distill | 0.901 | 0.999 | 0.930 | ≈0 | 0.0005 |
| student_control | **0.911** | 0.999 | 0.930 | ≈0 | 0.0027 |
| neg_gpt2 | 0.514 | n/a | n/a | n/a | n/a |
| neg_smollm2_360m | 0.515 | n/a | n/a | n/a | n/a |

| 指标 | DiffIP | 余弦 | CKA | QSh PCA32 |
|---|---:|---:|---:|---:|
| gap distill−control | **−0.010** | ≈0 | ≈0 | −0.002 |
| AUC distill vs control | **0.348** | ≈0.5 | ≈0.5 | <0.5 |
| wins distill>control | **10/32** | — | — | — |

说明：
1. 两个学生相对基座都很高（DiffIP≈0.90，余弦≈0.999）——它们都是基座的轻量 SFT，**指纹像微调衍生**，这本身合理。
2. **对照学生分数不低于甚至略高于蒸馏学生**，因此「是否用了教师文本」在表示几何上不可分。
3. 相对无关模型 gap 很大（0.90 vs 0.51），但那只说明「认出 SFT」，**不是**「认出蒸馏来源」。
4. 全维 QSh 留出 `exp(−L2)` 接近 0：残差尺度与 DiffIP（先 PCA-8）不可比；PCA-32 后 distill 仍不优于 control。诚实记录，不把近零 sim 解读成「QSh 否定衍生」。

## 5. Blocker 与未做项

1. **未新训更强学生**（同词表 logit KD / 同架构更大预算）：本机 CPU-only，完整重蒸成本高；既有学生已在行为指标上明显蒸进，仍无表示指纹信号。
2. 跨维时余弦 / QSh 不可用；若要坚持 QSh，需固定投影器或只在同维面板评。
3. 本轮 seed 仅 1 组、N=64（非 v3 全网格）；足够支持「分不开」的负结论，但置信区间未扫满。

## 6. 研究含义（如实）

- **DiffIP middle2 对「异架构序列蒸馏」目前不鲁棒**：藏层几何仍由学生基座主导。
- 对「同基座 SFT」敏感，但对「蒸馏 vs 普通指令微调」不敏感——若目标是防抽取/蒸馏溯源，需要输出层或行为层指纹，或同词表 logit 级监督下的更强学生再测。
- 准确率主线上，middle2 对微调/剪枝面板有效；**蒸馏线仍是负结果**，不能写进「已解决」。
