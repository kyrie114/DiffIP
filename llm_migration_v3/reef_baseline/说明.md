# REEF 基线对比（与 DiffIP v3 同一批模型对）

## 1. 依据（REEF 原文 / 官方代码）
- 论文：Zhang et al., *REEF: Representation Encoding Fingerprints for Large Language Models*, ICLR 2025, arXiv:2410.14273。
- 官方仓库 github.com/tmylla/REEF（本次 clone 的 main）：
  - `src/generate_activations.py::get_acts`：逐条输入、无 padding，hook `model.model.layers[l]` 输出，取 **最后一个 token**（`token_pos=-1`）。
  - `src/generate_activations.py::load_acts(center=True, scale=True)`：按维中心化 + 按维除以标准差（`compute_cka.py` 就这样调用）。
  - `src/compute_cka.py`：**默认 linear CKA**（`kernel_CKA` 即 RBF，sigma=中位数启发式，被注释掉），默认 `--base_layers 18`（LLaMA-2-7B 共 32 层），可算全层 CKA 矩阵。
  - `src/scripts/save_activation.sh`：`--downsample 200`，数据集 truthfulqa（另有 toxigen 等），即 **200 条样本**。

## 2. 本次协议
- 模型与 v3 完全一致（`common.build_model`）：victim=Qwen2.5-0.5B；衍生 fine_tune(Instruct)、weight_perm(权重置换)、rep_perm(表示置换)、scale(各向异性缩放)、prune(删 4 层, 共 20 层)；负例 SmolLM2-135M/360M、GPT-2、Pythia-160M、Qwen2-0.5B。rep_perm / scale 与 v3 `score.py` 相同，作用在 Instruct 的特征上。
- 输入：(a) **REEF 主设置**：TruthfulQA 原始 csv 随机 200 条（`random.Random(2024)`，2024 为 REEF 默认 seed），语句=Question+" "+Best Answer；(b) v3 的 32 个 prompt。
- 特征：每层末 token（REEF 原法）和 token 均值池化（v3 的池化方式）。
- 层：主结果 = 相对深度 18/31（victim 第 13 层；异构模型按各自层数取同一相对深度）；另报 9 个相对深度、末层、全层矩阵最大值。
- 同口径对照：在 v3 已采好的**扰动样本云**上（每个 prompt 的 N 个成对扰动样本，同 4 层）直接算 linear CKA，和 DiffIP 用的是同一份数据。

## 4. 分析
1. **置换/缩放对 REEF 是“构造上不变”**：linear CKA 对正交变换和各向同性缩放不变，REEF 还先按维标准化，所以对角缩放也被消掉。fine_tune / weight_perm / rep_perm / scale 四列完全相同，这不是检测能力的证据，而是公式性质。DiffIP 需要 ALS 去拟合 Q、S 才能做到同样效果（scale 略低 0.006）。
2. **REEF 官方设置在小模型上分不开剪枝和同族负例**：prune 0.875 < Qwen2-0.5B 0.910、SmolLM2-360M 0.895。无关模型的末 token CKA 都在 0.73–0.91，基线很高，所以间隔很小。REEF 原文用 7B 级模型，且给出的阈值是在他们的模型集上，本实验没有复现他们的数值，只说明在 0.5B 级、这 5 个负例上效果如此。
3. 改用均值池化后 REEF 勉强可分（间隔 +0.008 / +0.016），但 Qwen2-0.5B 仍高达 0.92–0.96。
4. **同一份扰动样本云上算 CKA，可分性和 DiffIP 一样好**（负例 0.20–0.30，间隔 +0.49）。说明 v3 的区分力主要来自“成对扰动采样”这一数据设计，度量换成 CKA 也成立；DiffIP 的 ALS 回拉 + L2 距离与 CKA 在这组实验中没有体现出谁更强，DiffIP 的逐 prompt AUC（0.956）反而略低于 CKA@扰动云（1.000），主要被 prune 在少数难 prompt 上拖低。
5. 结论：在相同模型对上，**REEF 官方设置（跨样本 CKA）对剪枝 vs 同族模型不可靠；DiffIP 的扰动云方案可分**；但这一优势在同样数据上用 CKA 也能得到，不能全归功于 ALS。

## 5. 偏差说明
- REEF 的 truthfulqa 语句文件未随仓库发布，这里用 TruthfulQA 原始 csv 自行拼接“问题+最佳答案”，抽样 seed=2024。
- 层的选择：官方默认第 18 层（7B, 32 层），这里换算成相对深度；剪枝模型按其自身 20 层取相对深度（并非与 victim 层一一对应）。全层矩阵最大值对所有衍生模型都是 0.998（第 0 层几乎相同），区分意义不大，仅列出。
- 官方 `compute_cka.py` 里 `test_layers = range(test_layers[0])` 的写法有歧义，本实验直接算全层矩阵，不依赖它。
- CPU、float32 运行；激活 `acts/`（302MB）未提交，可用 `collect.py` 重新生成（约 3 分钟）。
