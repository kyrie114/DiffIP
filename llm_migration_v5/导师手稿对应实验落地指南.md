## 三、 极重要提醒：度量指标（Metric）怎么选才能避免吃亏并稳赢 SOTA？

老师在模块 A 圈出了 **`Metric`（度量指标）**，并在左上角强调 **`同基座区分更强`**。这里有一个**决定论文成败的关键细节**：

### ⚠️ 绝对不能只比“正例原始相似度绝对值”！
- 因为 `REEF (CKA)` 在正例上是 `0.95–0.99`，但它在**完全无关的模型**（如 `Llama-2-7b vs llama-7b-hf [Llama-1]`、`Baichuan-7B vs mpt-7b`）上也高达 **`0.83–0.94`**！
- 而我们的 `DiffIP-LLM` 在 7B 正例上的原始相似度 `exp(-d)` 是 `0.36–0.56`，无关模型是 `0.253`。如果直接把 `0.36` 和 `0.99` 放在一起比绝对值大小，会非常吃亏！

### ✅ 正确的度量指标设计（与老师画的“多柱子 Metric + 同基座区分更强”完全吻合）
在主表和 16 个子图中，我们统一采用**衡量“同基座正例 vs 异基座负例区分能力”的无量纲指标**（每个子图里每个方法画 3 根柱子，带跨种子/跨探针标准差 `±` 误差棒）：

1. **柱子 1：`ROC AUC`（正负样本整体排序区分度，$\in [0, 1]$，越高越好）**
   - 含义：在该基座、该衍生类型下，将同基座衍生模型（跨 32 prompts / 3 seeds）作为正样本，其余无关基座模型（如另外 3–5 个基座）作为负样本计算的 ROC 曲线下面积。
   - 预期表现：我们的同 Prompt 相对判定 $\Delta_p$ 在剪枝、量化、微调上 **AUC $\approx 0.999\sim 1.000$**；而 `REEF` 因无关模型高分重叠（如 Llama-1 vs Llama-2、Baichuan vs MPT），AUC 显著偏低；`HuRef` 在剪枝（尤指删层/通道剪枝）和领域续训（CPT）上 AUC 暴跌。
2. **柱子 2：`TPR@5%FPR` 或 `Detection Accuracy`（低误报率下的检出率，$\in [0, 1]$，越高越好）**
   - 含义：固定假阳性率 $\text{FPR} \le 5\%$（或用留出种子标定阈值）时的真正例检出率（即你在 [实验维数层数结果.md](file:///d:/study/Diffip/llm_migration_v4/实验维数层数结果.md) 里算的留出召回率，`Ours` 高达 `0.97–1.00`）。
   - 预期表现：`AWM` 论文 Table 3 用的正是这个指标（`REEF` 在该指标上跌至 `0.300`）！用这个指标能最直观地展示老师说的**“同基座区分更强”**。
3. **柱子 3：`Normalized Separation Margin`（归一化正负区分裕度 / 信噪比 SNR）**
   - 定义：将每个方法的得分按无关负例分布做标准化（或计算相对参照裕度 $\Delta_p = \text{sim}_{\text{pos}} - \text{sim}_{\text{neg}}$），衡量同基座正例高出无关基座背景噪声多少倍标准差。
   - 同时，如果还加上你在 [实验报告.md](file:///d:/study/Diffip/llm_migration_v4/实验报告.md) 里的**线性/旋转伪装变体**作为 `Test` 列（对应老师手稿主表右侧的 `Test` 列！），`HuRef` 和 `AWM` 在保输出旋转+非恒定 RMSNorm 缩放下直接崩盘，而 `Ours` 保持 100% 检出！
