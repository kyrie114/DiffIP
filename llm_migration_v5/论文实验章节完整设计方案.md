### 实验设计 2：白盒与特征伪装鲁棒性实验（对应 Section 5.3, Table 4 & Figure 2）

为了全面对比 `HuRef`、`REEF`、`AWM` 和 `Ours` 的抗伪装能力，在 `Llama-2-7b-chat-hf (fine_tune)` 上设计 **5 种有明确针对性的伪装攻击（前 3 种和第 5 种你已经跑完 Ours 的数据，只需补跑基线对比）**：

| 伪装攻击类型 | 数学操作定义 | `HuRef` (ICS) | `REEF` (Linear CKA) | `AWM` (LAP + UCKA) | **Ours (DiffIP-LLM)** | 论文叙事重点 |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| **Attack 1：权重/通道置换** (`weight_perm` / `rep_perm`) | 对残差流与权重施加置换矩阵 $P$ | ⚠️（若动共享词表则退化） | ✅ 不变 | ✅ 不变 | ✅ **不变** (`0.364`/`0.363` vs `0.363`, 32/32) | 基础门槛：直接击穿朴素余弦 `PCS` (`0.000`) |
| **Attack 2：各向异性通道缩放** (`scale`) | 对隐状态/特征各通道乘非均匀对角矩阵 $S=\text{diag}(s_1,\dots,s_D)$ | ❌ / ⚠️ | ❌ **退化**（线性 CKA 仅对标量 $cX$ 不变，大方差通道主导核矩阵 $XS^2X^\top$） | ⚠️（Stage 1 仅容许标量 $c$ 与符号 $D$） | ✅ **严格不变** (`0.365` vs `0.363`, 32/32) | **凸显 ALS 相比线性 CKA 的理论与实测优势**：ALS 显式求逆对角矩阵 $S^{-1}$ |
| **Attack 3：保输出正交旋转 + RMSNorm 非恒定 $\gamma$ 操纵** (T3+T5 Attack) | 对词嵌入施加正交旋转 $R_{\text{emb}}$，修改 RMSNorm 缩放向量 $\gamma'\neq c\mathbf{1}$ 并吸收进相邻权重（前向输出逐位不变！） | ❌ **彻底崩溃**（ICS 从 `0.99` 跌至 `0.03–0.15`，见 `Indep. Tests` Tab. 15） | ✅ 不变（隐状态在残差流仅差正交旋转） | ❌ **Stage 1 崩溃**（正交旋转 $R_{\text{emb}}$ 非置换矩阵 $cPD$，破坏 $W_{\text{emb}}$ 列余弦指派） | ✅ **严格不变**（前向隐状态经 PCA+ALS 完美消去正交旋转 $Q$） | **一箭双雕击穿静态权重派（`HuRef` 与 `AWM`）**：证明静态权重代数假设一旦被打破即失效，而前向局部流形探针天然免疫 |
| **Attack 4：词表重映射 / 跨维度剪枝 + 置换** (`Tokenizer Re-init` / `Sheared` $D_1\neq D_2$) | 衍生模型更改词表映射（无已知共享 token 索引对应）或通道剪枝改变维度 $D_1\neq D_2$ | ❌ **无法运行/崩溃**（找不到对齐的 $\hat{X}$） | ✅ 可运行（但受制于高 FPR） | ❌ **Stage 1 崩溃**（无共享词表交集 $I$ 或 $D_1\neq D_2$ 时无法解方阵 LAP） | ✅ **稳健通过**（零词表交集依赖，独立 PCA 至 $d=8$ 后对齐） | **凸显动态局部探针相比 `AWM` 的解耦优势**：无需共享词表交集 $I=\text{Vocab}(A)\cap\text{Vocab}(B)$ |
| **Attack 5：9 种非线性特征变换 + 分位数正态化 + 无关激活掺入** (实验 C / E / G) | `pow0.5`, `tanh`, `scale+tanh`, `pow2`, `block64+pow0.5`, `lowrank tanh`, `layerpow`, `layermix`, `rankgauss`, 及等 RMS 掺入 25%/50%/75% `Llama-3` | N/A（仅静态权重） | 可同特征对比 | N/A（仅静态权重） | ✅ **8/9 变换 32/32 全胜**（`pow2` 仍 31/32；`rankgauss` 32/32；掺入 50% 仍 29/32） | 展示我们已跑完的压测结果，证明局部微扰流形对单调/温和非线性与特征污染具有极强韧性 |

> 💡 **实操提示（Attack 3 怎么实现最快？）**：
> Attack 3（T3+T5 保输出旋转+归一化缩放）甚至**不需要重新跑 7B 模型前向**！因为在保输出变换下，模型每一层输出到残差流的隐状态 $H_\ell$ 恰好变成 $H_\ell R_{\text{emb}}$（若攻击者同时把 RMSNorm 的非恒定缩放 $\gamma'$ 留在隐状态观测点之后，则变为 $H_\ell R_{\text{emb}} \text{diag}(\gamma')$）。你在已存的 `fine_tune` 特征上直接右乘一个随机正交矩阵 $R_{\text{emb}}$ 和非恒定对角阵 $\text{diag}(\gamma')$，同时对静态权重 $W_{\text{emb}}, W_Q, W_K$ 施加完全相同的变换喂给 `HuRef` 和 `AWM`：你会看到 **`HuRef` 和 `AWM` 的静态权重分数当场崩塌，而我们的 PCA+ALS 分数保持 `0.363–0.365`（32/32）纹丝不动**！这在论文里是一个极其漂亮、理论与实验完全闭环的亮眼结果。

### 实验设计 3：机制剖析与核心前提验证（对应 Section 5.4, Table 5 & Table 6 —— 100% 用已有数据！）

审稿人读完主表后一定会问两个“为什么”：
1. **为什么你们的单 Prompt 配对微扰点云不会像 REEF 那样在无关模型上产生高假阳性？**
2. **为什么你们一定要做“同 Prompt 相对差值 $\Delta_p$”？直接用原始相似度或者减一个常数不行吗？**

你**已经跑完的数据**恰好给出了完美的定量回答，直接做成两张极具说服力的消融表：

#### 3.1 Table 5：探测点云与对齐算子的解耦验证（来自 `本次实验报告.md` 实验 D + `实验DE结果.md` 实验 E）
1. **2×2 正交对照（0.5B 全矩阵，`本次实验报告.md` 第 4 节）**：
   - `异构句子 (TruthfulQA 200) + CKA`（即官方 REEF）：剪枝正例 `0.733` < 同族无关负例 `Qwen2-0.5B` `0.819`（正负倒挂），AUC = **`0.923`**；
   - `单 Prompt 配对微扰点云 + CKA`：正例全部高于负例，AUC = **`1.000`**；
   - `单 Prompt 配对微扰点云 + PCA+ALS (Ours)`：AUC = **`0.956`**（且在逐通道各向异性缩放下保持严格不变）。
   - **结论**：证明剥离“跨句子宏观语义混杂”、转向“单点局部流形探测”是消除无关模型高假阳性的第一性原因。
2. **打破种子配对消融（7B 主线，`实验DE结果.md` 实验 E `shuffle`）**：
   - 保持 `fine_tune` 的 128 个微扰隐状态完全不变，仅**随机打乱样本索引配对（`shuffle`）**；
   - 结果：相似度从 **`0.363±0.006`（胜率 32/32）直接暴跌至跨家族地板 `0.253±0.008`（胜率 5/32）**！
   - **结论**：证明我们的指纹捕获的**纯粹是同一随机噪声方向下的输入-输出局部配对几何（Local Jacobian Correspondence）**，而非激活值的边缘分布统计量（因为即使把边缘分布强行正态化 `rankgauss`，只要保留配对，依然是 `0.348`、32/32 全胜！）。

#### 3.2 Table 6：同 Prompt 相对差值 $\Delta_p$ 的必要性证明（来自 `实验ABC结果.md` 实验 B + `实验FG结果.md` 实验 F）
将你已经跑出的 4 组数字并列成表：
- **跨 Prompt 强共变现象**：在 7B 上，`fine_tune` 与无关负例（`Qwen2.5-7B`、`Llama-3-8B`）在 32 个 Prompt 上的原始绝对分数相关系数高达 **$r = 0.956$**（且去除 Prompt 长度后偏相关仍为 $0.956$）。
- **四种判定规则在 7B 留出集上的正面对比（`实验FG结果.md` 实验 F）**：
  1. **不减参照（原始绝对分数全局阈值，实验 B）**：Held-out 部署 AUC = **`0.702`**，留出 SFT 召回率仅 **`0.0625`**（完全不可用）；
  2. **跨规模硬搬 0.5B 绝对阈值（实验 B 命题 T）**：0.5B Youden 阈值（`t=0.670`）在 7B 上仅接受 **`15.4%`** 的 SFT 正例（误拒 84.6%）；
