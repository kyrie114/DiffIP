# 口径修正与跨基座尺度失配根因诊断说明

> **核心发现（基于服务器已跑完数据与 [diffip/reversion.py](file:///d:/study/Diffip/diffip/reversion.py) 源码严格核对）**：
> 上一轮服务器上产出的 [summary_metrics.json](file:///d:/study/Diffip/llm_migration_v5/sota_scores/summary_metrics.json) 中，之所以出现“**`Base A` 在同口径 [matched_rule.json](file:///d:/study/Diffip/llm_migration_v5/sota_scores/matched_rule.json) 下 AUC 高达 `0.9998`，但主表 [main_table_and_efficiency.md](file:///d:/study/Diffip/llm_migration_v5/sota_scores/main_table_and_efficiency.md) 却只报 `0.52–0.76`，且 `Base C (Qwen3)` 全近 `0.001`、`Base D (MPT)` 全挤在 `0.930`**”，背后恰好是两个完全可定位的数学原因：

---

## 原因一：`evaluate_all()` 对 `Ours` 错用了“未校准的逐 Prompt 原始分数 AUC”

1. **Bug 位置**：原 `suite_sota.py` 的 `evaluate_all()` 把 `Ours` 在 32 条不同 Prompt 上的原始绝对相似度（`[32, 3]`）直接拼接后与负例原始绝对相似度算 ROC AUC。
2. **为什么会失真？** 我们在实验 B/F 已证实，所有模型在 32 条 Prompt 上的绝对分数存在 **$r = 0.956$ 的题目难易共变**：简单 Prompt（如 Prompt 23）上无关负例也会高达 `0.814`，而困难 Prompt 上微调正例也会低到 `0.01–0.15`。把不同题目的绝对分数混成一个桶算 AUC，本质上是在测“题库难度排序”，而不是测“同题谱系区分”。
3. **验证证据**：只要用 `Ours` 真正的 **同 Prompt 相对间隔 $\Delta_p = S(M_{\text{sus}}, p) - S(M_{\text{ref}}, p)$**（[matched_rule.json](file:///d:/study/Diffip/llm_migration_v5/sota_scores/matched_rule.json)）或按探针集均分（3 个种子点 vs 负例种子点）：
   - `Base A` 部署 **AUC = `0.9998`、`Accuracy = 99.04%`、`F1 = 0.9946`**（相反 `REEF`/`HuRef`/`AWM` 在同规则 [same_rule_others.json](file:///d:/study/Diffip/llm_migration_v5/sota_scores/same_rule_others.json) 下通过率仅 `2/20`、`7/20`、`9/20`，FPR 全高达 `50%`）；
   - **`Base B (Llama-3-8B)` 同样本来是有明确正向间隔的**：`pruning` margin `+0.0415`、`quantization` `+0.0751`、`finetune` `+0.0881`（均远高于无关模型极差 `0.001`），之前被原始混合口径掩盖成了 `0.57–0.64`。

---

## 原因二：未归一化 ALS 残差受受害模型隐状态能量 $\|Y_c\|_F^2$ 主导（导致 Qwen3 下溢、MPT 压缩）

检查 [diffip/reversion.py](file:///d:/study/Diffip/diffip/reversion.py#L19-L71)：
```python
residual = rotation @ (scale[:, None] * suspect_columns) - victim_columns
distance = ||residual||_F^2 / sample_pairs
```
在带自由对角缩放 $\Lambda$ 的线性回归中，残差 MSE 严格满足：
$$\text{MSE}(X \to Y_l) = \underbrace{\frac{1}{N}\|Y_{c,l}\|_F^2}_{\operatorname{Var}(Y_l)} \cdot \bigl(1 - R_l^2(X \to Y_l)\bigr)$$
由于旧代码**没有除以受害模型该层的特征能量 $\operatorname{Var}(Y_l)$**，导致跨架构出现剧烈两极分化：
- **`Qwen3-8B-Base`（Base C）**：中间层（第 12、23 层）微扰激活能量极高，哪怕保留较高相关性，未归一化距离也跳到 `210` 与 `189`（见 [进度.md](file:///d:/study/Diffip/llm_migration_v5/%E8%BF%9B%E5%BA%A6.md) 第 41 行），把第 0 层（相似度 `0.998`）和末层（`0.608`）彻底淹没，导致 $\exp(-\overline{d}) \approx 0.0008$ 数值下溢；
- **`mpt-7b`（Base D）**：因低精度归一化输出方差极小（$\operatorname{Var}(Y_l) \approx 0.08$），哪怕纯无关模型 ($R^2 \approx 0$)，未归一化距离也 $\le 0.08$，使得所有模型（正负例）全被压缩在 $\exp(-0.08) \approx 0.926\text{--}0.930$ 的天花板缝里。

### 解决方案（无需重新提取任何模型特征！）
在 [suite_sota.py](file:///d:/study/Diffip/llm_migration_v5/suite_sota.py) 中我们保持原始 `score_ours_pair` 不变以兼容 `Base A` 已冻结结果，同时新增两项零 GPU 前向工具：
1. **已修复 `evaluate_all()` 口径**：`Ours` 主指标 `auc` / `tpr_at_5fpr` 改为严格按同 Prompt 相对间隔 $\Delta_p$ 跨参照配对均值计算，同时输出探针集均分 `probe_auc` 并保留 `raw_prompt_auc`。
2. **新增 `score_ours_pair_normalized()` 与 `python suite_sota.py diagnose_bases`**：逐层用受害者当前层方差归一化（$\mathrm{nMSE}_l = \text{MSE}_l / \operatorname{Var}(Y_l) = 1 - R_l^2 \in [0, 1]$），在不改变任何嫌疑侧 $\mathrm{GL}(d)$ 仿射不变性的前提下，消除 Qwen3 中间层量级轰炸与 MPT 低方差压缩，使第 0/中前/中后/末 4 层严格等权贡献。
3. **图表全面去乱码**：已将 [fig1](file:///d:/study/Diffip/llm_migration_v5/figs_sota/fig1_16subplots_4bases_4types.png)–[fig5](file:///d:/study/Diffip/llm_migration_v5/figs_sota/fig5_mechanism_and_calibration.png) 全部转为规范英文图注、修复 `Fig.1` 与 `Fig.3(a)` 图例遮挡、修复 `Fig.5(a)` 横坐标重叠与 `Fig.1` y 轴底部截断。
