# 实验

三件事分开写。20 对留出、四基座主表、P0 扩池各用各的门限。后一节的高分不改写前一节的失败。

## 1. 冻结的 20 对同题间隔

受害模型是 Llama-2-7B。五个无关模型两两做参照和留出，共 20 个方向。种子 0 用留出负例自己的最大间隔定阈值，种子 1 和 2 才计数。强剪枝每个种子 96 条，微调簇每个种子 160 条。中文衍生不进通过线。

通过 18/20。claim_holds 为假。失败的两对是 neg_qwen2_5_7b 到 neg_mpt_7b，以及 neg_llama3_8b 到 neg_mpt_7b。

种子 1 和 2 合并后，正确数是 11409/11520。

同一批事先登记、并且没有通过的线是：同云线性 CKA 19/20，同维扰动余弦 0/12，Qwen3 第二底座 0/12。DiffIP 新种子 max1 18/20，band 19/20，band 未确认。max2 20/20。新种子上的同云 CKA 三条规则另计，不把冻结门限改成全通过。

## 2. 四基座归一化主表

四个基座是 Llama-2-7B、Llama-3-8B、Qwen3-8B、MPT-7B。主表分数是逐层方差归一化残差。Ours 四基座均值是 0.9995 / 0.9999 / 0.9999 / 0.9757。伪装列是置换 0.6349，各向异性缩放 0.6025，旋转加 RMSNorm 0.6201。缩放后的分数是 0.6025，干净分数是 0.6349。

## 3. P0 扩池，以及它到不了的边界

这一节用的仍是原来的 20 组阈值，没有在这 11 个模型上重拟合。

FuseLLM 对扩展负例池的间隔 AUC 是 0.4979 / 0.3881。Abel 是 0.4987 / 0.4633。预先写的线是 AUC 至少 0.90。两格都低于这条线。20 个方向里召回达到 0.90 的个数，两个正例都是 0。

9 个新负例的平均误报是 0.0282，不超过 0.05。最差方向的误报不超过 0.10 的，只有 1 个，分母是 9。

REEF 的偶/奇阈值是 0.9741 和 0.9776。FuseLLM 全量 CKA 0.9961，偶定奇测和奇定偶测都触发。Abel 全量 CKA 0.9555，两个方向都不触发。OpenChat 和 Starling 的全量 CKA 都是 0.953086，逐位相同。

internlm2-base-7b 的前向是非有限值，没有分数。

四基座表上剪枝、量化和微调接近满分，不覆盖这一节。融合模型和数学继续预训练没有被 DiffIP 从无关底噪里分开。
