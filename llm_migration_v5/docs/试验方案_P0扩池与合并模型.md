# P0 扩展实验方案：模型融合/合并衍生（FuseLLM）与大负例池（6 → 16+）验证（2026-11-26）

## 一、实验目的与预注册背景

本方案利用服务器 `/data/luo_lixuan/llms` 中已有模型（零额外下载开销），针对审稿人最关注的两个广度缺口执行受控补充验证：

1. **补充模型融合 / 分布合并（Model Merging）与额外领域 CPT 衍生（P0-A）**：
   - `FuseLLM-7B`：REEF 论文原班评测的分布融合衍生模型（基于 `Llama-2-7B`），验证 **DiffIP-LLM** 在跨模型知识融合下的血缘检出能力；
   - `Abel-7B-002`：基于 `Llama-2-7B` 的数学推理领域衍生，进一步充实 Domain CPT 衍生池。
2. **独立无关负例池从 6 个扩至 16 个（P0-B）及可选大尺寸 / MoE 负例（P0-C）**：
   - 新增 10 个本地 7B 独立基座/异构衍生负例：`open_llama_7b_v2`、`internlm2-base-7b`、`OLMo-2-1124-7B-Instruct`、`bloom-7b1`、`pythia-6.9b`、`opt-6.7b`、`RedPajama-INCITE-7B-Base`、`chatglm2-6b`、`openchat_3.5`、`Starling-LM-7B-alpha`；
   - 可选（`--include-large`）加入 2 个跨体量/MoE 负例：`Mixtral-8x7B-Instruct-v0.1`（MoE）与 `internlm2-chat-20b-llama-old`（20B）。

## 二、预注册协议与通过判据（写死于运行前）

### 1. 特征提取配置（与论文主线完全对齐）
- **DiffIP-LLM**：连续嵌入配对高斯微扰 $\sigma = 2 \times 10^{-3}$，采样云 $N = 128$，均匀四层 `even4`，共享 PCA 维度 $d = 8$，主种子 `{123, 1123, 2123}`，32 条五领域探针；同时计算 Raw MSE（公式 (9)）与方差归一化 $1 - R_\ell^2$（公式 (10)）两种口径。
- **REEF 同步对照**：在 `TruthfulQA` 前 200 条陈述上提取每层最后 token 隐状态，按已登记规则评估 Layer 18（总层数 $\le 18$ 时取与 Victim L18 最大 CKA 层）的 `full200`、`3×128 bootstrap` 以及 100/100 `Even/Odd` 留出拆分。

### 2. 零泄漏通过判据
- **冻结门限**：严格复用 `sota_scores/matched_rule.json` 中由原 5 个独立基座在种子 0（`123`）上标定好的 20 组有序开集阈值 $\tau_0(R_{\mathrm{neg}}, M_{\mathrm{hold}})$，**不对任何 P0 新模型重新拟合阈值**。
- **P0-A（新正例）**：在未见留出种子 `{1123, 2123}` 上，报告 20 方向平均检出率（TPR）及相对扩展负例池（16+）的 `ROC AUC` 与 `TPR@5%FPR`（期望 Raw/Norm 均值显著高于负底线，AUC $\ge 0.90$）。
- **P0-B/C（新负例）**：
  1. **无关底噪锁定**：Raw MSE 与 $1 - R_\ell^2$ 均值均稳定落入既有无关底噪带（约 `0.252–0.255` 与 `0.376–0.380`）；
  2. **零泄漏误报**：直接套用原 20 方向冻结门限 $\tau_0$ 在未见种子 `{1123, 2123}` 上评测，检验平均 $\mathrm{FPR} \le 0.05$ 且通过全部/绝大部分方向（单模型 $\mathrm{FPR} \le 0.10$）。
- **REEF 对照**：观察其在扩大后的 16 负例池与 `FuseLLM-7B` 上是否出现更多误报或漏报。

## 三、服务器运行命令

```bash
cd llm_migration_v5
bash run_p0_expanded.sh            # 默认跑 2 个新正例 + 10 个 7B 新负例（共 12 个模型）
# 如需连同 Mixtral-8x7B 与 InternLM2-20B 一并测试：
bash run_p0_expanded.sh --include-large
```

运行完成后将生成的 `sota_scores/p0_expanded_pool_result.json` 与 `docs/表_P0扩池与合并模型.md` 提交并推送至 GitHub 即可合入论文。
