# 蒸馏线重做：更充分蒸馏的异架构学生，DiffIP20 / CKA / 余弦能否认出（2026-10-25，CPU）

## 1. 旧学生是怎么来的、为什么弱
来源 /workspace/distillfp（实验报告.md、distill_final.py、logs/distill_train_v2_epoch0.log）：
- 学生 GPT2-124M，教师 **Qwen2.5-0.5B（base）**；数据为 MMLU 题，教师只给 **ABCD 四个字母的分布**，4000 例（2000 题 × 2 种选项置换）；
- 损失只在答案位置：KL(教师4路分布)+CE(教师argmax)；batch 16、lr 5e-5、**1 个 epoch**（约 250 步，1206 s，loss 1.7565）。
- 弱的原因：每条样本只有 1 个位置、4 个类别的监督，总信号量极小；loss 停在均匀基线（≈1.72）附近；留出教师一致率 0.330→0.350，金标 0.235→0.225（随机级）。基本没蒸进去。

## 2. 新配方（gen_teacher.py, train_student.py）
- 教师：Qwen2.5-0.5B-Instruct（d=896，24 层，词表 151k），用 chat 模板对 Alpaca 指令（无 input 字段，回答 20–600 字符，随机 1720 条）**贪心生成**，max_new_tokens=128；1600 条训练，120 条留出。生成耗时 1095 s。
- 学生：SmolLM2-135M base（d=576，30 层，词表 49k，异架构异词表）。
- 蒸馏方式：**序列级 KD**（Kim & Rush 2016）：在教师回答上做 CE，只对回答 token 计损失。与原计划的差别：词表不同，无法逐 token 对齐教师 logits，所以没做 logit KD，这一点要注明。
- 超参：batch 8，lr 1e-4（30 步预热后线性衰减），3 epoch = 600 步，截断 320 token。distill 1121 s，loss 1.206 / 0.707 / 0.449。
- 对照学生：同基座、同指令、同步数和超参，只是回答换成 Alpaca 原始回答（text-davinci-003 写的，非教师）。990 s，loss 1.710 / 1.112 / 0.746。

## 3. 蒸馏强度（eval_strength.py, strength.json；120 条留出指令，训练未见）

|---|---|---|---|---|---|---|
| SmolLM2-135M 基座 | 0.3475 | 0.601 | 0.397 | 0.551 | 0.123 | 0.154 |
| **蒸馏学生** | **0.2564** | **0.675** | 0.484 | 0.534 | **0.260** | 0.183 |
| 对照学生 | 0.3947 | 0.575 | 0.379 | 0.582 | 0.200 | 0.274 |

参照：Alpaca 原始回答与教师回答的 ROUGE-L 为 0.194。
- top-1 命中是在学生分词下对教师贪心文本做教师强制得到的，可以看作和教师选择的一致率。它不是同词表的 logit 一致率，KL 也算不了（词表不同）。
- 结论：这次蒸馏确实蒸进去了，而且是有针对性的。教师文本的 NLL/字节降了 26%，对照学生反而变差（+14%）。ROUGE vs 教师翻倍（0.12→0.26），高于对照（0.20）和 Alpaca 参考（0.19）。生成内容也明显带上教师风格（"we need to consider several factors: 1. **…**"）。比旧学生强很多，但离"学生≈教师"还很远（135M、1600 条、CPU）。

## 5. 结论（负结果）
1. 蒸馏学生虽然真的学到了教师的输出行为（见第 3 节），但隐藏表示几乎没动：它和教师的相似度跟未蒸馏基座、对照学生相差不到 0.003，各方法都一样。分数主要由学生的基座和架构决定，与是否蒸馏无关。最高的负样本是 Qwen2-0.5B（同家族）和 SmolLM2-360M。
2. 所以 **DiffIP20 回拉在这个异维度蒸馏场景下并没有认出学生**，CKA 两种口径也没有。"回拉能处理不同维度"在形式上成立（能算出分数），但没有带来区分力。四种方法打成平手，都失败。
3. 机理上的判断（未单独验证）：序列级蒸馏只约束输出分布，学生用的是它自己预训练出来的表示几何。所有 last-token 隐藏状态方法（CKA、DiffIP）比较的都是几何，因此对蒸馏天然不敏感。要检测蒸馏，可能需要输出层或行为层的指纹（例如教师特有的输出偏好），而不是隐藏层。
4. 局限：只有 1 个正样本，AUC 只有 3–6 个对比，统计意义很弱；学生小，数据只有 1600 条；没有做 logit KD；没有更长或更强的蒸馏，不能排除"蒸得更狠以后几何也会靠近"。但在本次"行为上已明显靠近"的强度下，隐藏层方法看不到信号。
